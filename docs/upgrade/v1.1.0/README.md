## 版本概述

在 v1.0.0 上新增 Windows 原生托盘与窗口恢复，调整关闭窗口行为，修复已安装 Windows 版本因迁移 SQL 换行差异导致的数据库初始化失败。仍仅发布 Windows x64 与 macOS arm64，各有安装版和便携版。

## Windows 窗口与托盘

- EXE 使用 GUI 子系统，debug/release 启动不再附带命令行窗口；启动失败以可读对话框反馈。
- 关闭按钮和 Alt+F4 默认收起到托盘，网关、在途请求及账号后台任务继续运行。
- 单击、双击、键盘激活或托盘菜单恢复原窗口；同一数据目录再次启动时唤起已有实例。
- 托盘菜单“退出 Tiny Proxy”及设置“退出应用”显式退出，沿用后台关停、请求取消与记录收尾路径。
- 托盘不可用时保持窗口可操作；Explorer 重启时尝试重新注册图标，失败时恢复窗口并显示原因。

## 数据库启动修复

迁移 SQL 在仓库和运行时统一为 LF。迁移校验仅额外认可同一条内嵌 SQL 的精确 CRLF 历史校验值，保持历史迁移记录不变；其他内容变化、未知版本和未完成迁移仍拒绝。数据库初始化错误区分校验冲突、文件损坏、占用、只读、访问失败和磁盘空间问题，并显示路径，不回显保存数据或原始 SQL。

## 行为与界面变化

Windows 的关闭窗口由退出改为收起，需要从托盘或设置显式退出才能停止网关。设置同时说明当前平台的退出规则。macOS 关闭窗口仍退出，本版不新增 macOS 托盘。设备码登录、模型 API、密钥边界和在线更新确认流程沿用 v1.0.0。

## 配置与数据兼容性

继续使用迁移 0001–0008，没有新增表、字段或迁移版本。LF、精确 CRLF 或二者混合的历史迁移可识别；仅完成部分旧迁移的数据库继续应用后续 LF 迁移。真实数据库及其迁移记录不需要删除、重写或清空。

数据目录和凭据边界不变：Windows 为用户级 DPAPI，macOS 为本机钥匙串密钥与 AES-256-GCM 密文。复制数据库不能跨用户、设备或平台恢复凭据。

## 升级说明

从 v1.0.0 升级前保留一致性数据库备份并完全退出旧应用。Windows v1.0.0 关闭窗口会退出；本版及后续托盘版应使用托盘或设置退出。应用内更新仍需手动下载、校验并确认安装重启；安装器或便携包沿用既有数据目录。

遇到数据库启动错误时保留 app.db 与配套文件，按错误原因检查；不要删除数据库或修改 _sqlx_migrations 的校验值。回退到 v1.0.0 前保留备份，旧版本仍可能受迁移换行校验冲突影响。

## 破坏性变更与已知问题

- Windows 关闭窗口不再终止服务。需要显式退出才能释放端口、结束后台任务或替换程序。
- 本版按用户要求跳过 Rust/Python 测试，新增托盘、数据库兼容及实际安装升级尚未运行验证；构建成功不能替代这些验收。
- 托盘依赖 Windows Explorer 与交互式桌面；失败时保留可见窗口。macOS 托盘、开机自启和远端账号撤销仍未实现。
- 尚未配置 Windows 代码签名、Developer ID 或 Apple 公证；macOS app 为 ad-hoc 签名，安装器未公证。

## 验证结果

用户于 2026-10-14 明确要求“正式发版 跳过测试”，授权本次版本准备、提交推送、四包构建及正式发布。Rust 单元/集成测试和 Python 发布工具测试均跳过，不能沿用 v1.0.0 的测试结果声称本版测试通过。版本标记仅作用于本版，后续无 skip 标记的版本恢复默认测试。

本版保留资料一致性、格式、Clippy、原生 release 构建、打包及 SHA-256 清单核对；实际结果在任务结束后补记。本机不启动新版窗口或安装器，不使用真实数据库进行迁移演练。

## 变更依据

最近真实祖先正式版本是 v1.0.0（4360bb732925c179953ee59ab9aad58adf35e54d），代码依据为 c55f8d8b473d694c51478cd87651fa5dd36c9271 的 Windows 生命周期与迁移兼容改动。相较前版新增托盘功能，按规范递增 MINOR 至 1.1.0。本次同时完善 Native checks 对单版本 skip 策略的识别，跳过测试而保留其他检查。

目标新标签为 v1.1.0，不复用 v1.0.0；实际发布后可查看 [v1.0.0...v1.1.0](https://github.com/ynx-official/tiny-proxy/compare/v1.0.0...v1.1.0)。
