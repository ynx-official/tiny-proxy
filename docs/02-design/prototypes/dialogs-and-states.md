# 操作弹窗与异常状态

状态：Review  
最后更新：2026-10-13  
关联文档：[原型入口与覆盖表](../ascii-prototype.md)、[桌面流程](../desktop-flows.md)

D01—D12 是可复用操作弹窗；E01—E04 是全局/列表异常状态样例。撤销、退出、删除均为原型，尚未执行任何真实操作。

[返回原型总览](../ascii-prototype.md)

## D01

**创建客户端密钥**

从 [W06](onboarding.md#w06)、[P07](main-pages.md#p07) 或 [P08](main-pages.md#p08) 打开；创建动作需要明确点击。

```text
+------------------------------------------------------------------------+
| 创建客户端密钥                                                [ X ]    |
+------------------------------------------------------------------------+
| 给使用它的设备或 Agent 起一个名字。                                    |
|                                                                        |
| 名称  [ Trae - 笔记本                                      ]           |
|                                                                        |
| 这把密钥允许调用当前活动连接可用的模型。                               |
| 创建后只展示一次完整密钥，请及时保存。                                 |
|                                                                        |
| [ 取消 ]                                            [ 创建密钥 ]       |
+------------------------------------------------------------------------+
```

- 名称必填、去首尾空白、建议最多 40 字符；重复名称提示区分设备，但标识按内部 key ID。
- 创建中禁用重复提交；存储失败不显示明文成功页，保留名称供重试。
- 成功只进入一次 [D02](#d02)；取消回到来源页面，首次向导停在网络已保存状态。

## D02

**密钥创建成功 / 仅展示一次**

只有成功创建的当次会话可见，不可从列表再次打开。

```text
+--------------------------------------------------------------------------------+
| 客户端密钥已创建                                                               |
+--------------------------------------------------------------------------------+
| 名称：Trae - 笔记本                                                            |
|                                                                                |
| 完整密钥                                                                       |
| [ <只在此处显示的新密钥>                                    ] [ 复制 ]         |
|                                                                                |
| 关闭后无法再次查看。请保存到需要调用模型的客户端中。                           |
| 这不是你的上游账号登录凭据。                                                   |
|                                                                                |
| [ ] 我已保存这把密钥                                                           |
|                                                                                |
|                                                [ 完成 (未勾选时禁用) ]         |
+--------------------------------------------------------------------------------+
```

- 勾选后完成：向导回 [W07](onboarding.md#w07)，日常回 [P07](main-pages.md#p07)/[P08](main-pages.md#p08)；禁用 Esc 和遮罩误关闭，保留正常应用退出行为。
- 只有主动点击才复制明文，不自动写剪贴板、不写日志、不混入其他连接配置的复制结果。
- 若进程崩溃导致明文丢失，列表保留已创建密钥，可创建替代并撤销旧密钥，不能承诺找回。

## D03

**撤销密钥确认**

来自 [P07](main-pages.md#p07)。显示当前受影响的请求数量。

```text
+----------------------------------------------------------------------------+
| 撤销并删除客户端密钥？                                                     |
+----------------------------------------------------------------------------+
| Trae - 笔记本  /  key_demo_a                                               |
|                                                                            |
| 新请求将立即被拒绝。                                                       |
| 这个密钥关联的 2 个进行中请求将被取消。                                    |
| 其他密钥和账号登录不受影响。                                               |
|                                                                            |
| 此密钥撤销后删除且不再展示。客户端需要改用新密钥。                         |
|                                                                            |
| [ 取消 ]                                           [ 撤销并删除 ]          |
+----------------------------------------------------------------------------+
```

- 撤销中按钮禁用；只有删除提交成功才移除列表行、清除对应明文预览和终止对应任务。2026-10-13 按用户要求更新，依据 [B20](../../01-requirements/business-rules.md)。
- 失败保留原记录与原因，不能先隐藏再忽略存储错误。

## D04

**切换活动账号确认**

来自 [P02](main-pages.md#p02) 的设为当前。

```text
+------------------------------------------------------------------------------+
| 切换当前连接？                                                               |
+------------------------------------------------------------------------------+
| 现在：个人连接 A                                                             |
| 切换到：工作连接 B / 工作区 B                                                |
|                                                                              |
| 之后的新请求使用工作连接 B。                                                 |
| 正在进行的 2 个请求仍使用个人连接 A。                                        |
| 可用模型列表将随连接切换。                                                   |
|                                                                              |
| [ 取消 ]                                               [ 切换连接 ]          |
+------------------------------------------------------------------------------+
```

- 目标需有可用登录和模型权限；不可用时禁用切换，提供重新登录/授权入口。
- 切换事务失败时保留原活动连接；切换成功后若目标目录同步失败，新连接仍为当前连接，模型区显示同步错误，不能显示旧账号缓存。不能把已开始的请求迁移到新账号。
- 添加连接登录成功后也可复用此弹窗；当前没有活动连接时显示“设为当前连接”。

## D05

**退出账号连接确认与结果**

来自 [P03](main-pages.md#p03)。这里是登录会话退出，不是退出整个桌面程序。

```text
+--------------------------------------------------------------------------------+
| 退出个人连接 A？                                                               |
+--------------------------------------------------------------------------------+
| 该连接的 2 个进行中请求将被取消。                                              |
| 新请求将无法使用此连接。                                                       |
|                                                                                |
| 应用会尝试撤销远端会话，并清除本地登录凭据。                                   |
| 保留连接名称和注册信息，便于以后重新登录。                                     |
|                                                                                |
| 若这是当前连接，服务仍监听，但暂时不能完成模型请求。                           |
|                                                                                |
| [ 返回 ]                                             [ 退出此连接 ]            |
+--------------------------------------------------------------------------------+
```

- 提交后同弹窗显示“正在退出”，停止使用凭据；不提供继续发送模型请求的按钮。
- 全部成功：显示“已退出”，返回 [P02](main-pages.md#p02)；远端失败：显示“本地已退出，远端撤销未确认”，提供“前往 ChatGPT 管理授权”和“完成”。
- 没有无限等待；网络失败与远端已撤销分开展示，不自动切到另一个账号。

## D06

**删除账号连接确认**

来自 [P03](main-pages.md#p03)。删除和退出明确区分。

```text
+--------------------------------------------------------------------------------+
| 删除个人连接 A？                                                               |
+--------------------------------------------------------------------------------+
| 将退出此连接并移除本机保存的连接记录。                                         |
| 若要继续使用，需要再次添加连接。                                               |
|                                                                                |
| 其进行中请求将被取消。                                                         |
| 客户端密钥仍保留；已有请求元数据按保留规则处理。                               |
| 删除后的历史记录用“已删除连接”表示来源。                                       |
|                                                                                |
| 这是本地逻辑删除；不保证清除备份中的历史数据。                                 |
|                                                                                |
| [ 取消 ]                                             [ 退出并删除 ]            |
+--------------------------------------------------------------------------------+
```

- 执行与 [D05](#d05) 共用远端撤销/本地退出逻辑，再移除注册记录。
- 删除当前连接后不自动切换；概览显示未选择可用连接。
- 失败区分远端撤销未确认、退出成功但本地记录删除失败；不要统一显示“全部删除”。

## D07

**修改监听地址与应用配置**

来自 [P06](main-pages.md#p06)；向导共用字段，但运行中会额外说明重启影响。

```text
+------------------------------------------------------------------------------------+
| 修改访问地址                                                              [ X ]    |
+------------------------------------------------------------------------------------+
| ( ) 仅本机     127.0.0.1                                                           |
| (*) 局域网     [ 以太网 / 192.168.50.10                          v ]               |
| ( ) 个人 VPN  [ 选择 VPN 网卡                                   v ]                |
|                                                                                    |
| 端口 [ 8788     ]                                                                  |
|                                                                                    |
| 新配置：192.168.50.10:8788                                                         |
| 当前配置：192.168.50.10:8787                                                       |
|                                                                                    |
| [!] 应用时会停止旧监听，最多等待 10 秒后取消剩余请求。                             |
|     当前进行中请求：2。客户端需要同步修改地址。                                    |
|     绑定新地址失败时，服务保持停止并显示原因。                                     |
|                                                                                    |
| [ 取消 ]                                               [ 保存并重启服务 ]          |
+------------------------------------------------------------------------------------+
```

- 服务停止时主按钮为“保存配置”，不自动启动；运行中点击主按钮即已确认此次重启影响，不重复弹确认。
- 执行中显示 [D08](#d08) 的停止进度，然后保存并尝试新绑定；失败停留 [E03](#e03)，保留新配置供修正，不悄悄退回其他网卡。
- 无地址、非法端口、网卡失效会原位报错并禁止提交。编辑期间不触碰实际监听。

## D08

**停止服务 / 处理在途请求**

概览、接入页、托盘均进入同一停止流程；修改地址后的停止复用进度。

```text
+--------------------------------------------------------------------------------+
| 停止模型服务？                                                                 |
+--------------------------------------------------------------------------------+
| 当前进行中请求：2                                                              |
|                                                                                |
| 停止后不再接受新请求。                                                         |
| 默认等待最多 10 秒，随后取消仍未结束的请求。                                   |
|                                                                                |
| [ 返回 ]               [ 立即停止 ]               [ 等待后停止 ]               |
+--------------------------------------------------------------------------------+
```

- 等待后停止：原位显示“正在停止 / 剩余请求数 / 最多剩余秒数”，不再允许新请求。
- 停止过程中可立即停止，但不提供含糊的“取消”以恢复半停止状态。
- 没有在途请求时立即完成停止，不额外等待；成功关闭弹窗并更新所有页面和托盘。
- 停止失败保持可见错误和实际状态，不能显示“已停止”但端口仍接受请求。

## D09

**退出应用确认**

显式退出且存在在途请求时显示；没有请求时直接执行正常退出。

```text
+------------------------------------------------------------------------------+
| 退出 Tiny Proxy？                                                            |
+------------------------------------------------------------------------------+
| 当前进行中请求：2                                                            |
|                                                                              |
| 退出会停止模型服务并结束后台任务。                                           |
| 不会退出你保存的 ChatGPT 连接。                                              |
|                                                                              |
| [ 返回应用 ]            [ 立即退出 ]            [ 等待后退出 ]               |
+------------------------------------------------------------------------------+
```

- 等待最多 10 秒后取消剩余请求并退出；立即退出也先取消/回收任务，不直接强杀进程。
- 区分关闭窗口入托盘、退出应用、退出账号三种动作；提示语不混用。
- 若用户设置关窗为退出，走同一流程。退出遇到不可安全中断的本地事务时明确显示正在收尾。

## D10

**清理请求记录确认**

来自 [P10](main-pages.md#p10)、[S03](settings-and-system.md#s03)，或缩短保留期限后的保存确认。

```text
+----------------------------------------------------------------------------------+
| 清理请求记录                                                                     |
+----------------------------------------------------------------------------------+
| 范围  (*) 当前筛选结果     ( ) 全部已结束记录                                    |
|                                                                                  |
| 预计移除：24 条已结束请求记录（示例）                                            |
|                                                                                  |
| 不会取消进行中的请求。                                                           |
| 不会删除客户端密钥或账号连接。                                                   |
| 进行中的请求结束后，仍会按记录规则保存。                                         |
|                                                                                  |
| 这些本地记录清理后无法从本应用恢复。                                             |
|                                                                                  |
| [ 取消 ]                                                   [ 清理记录 ]          |
+----------------------------------------------------------------------------------+
```

- 在设置页打开时默认全部已结束记录；从记录页打开时显示当前实际筛选摘要。
- 保留期限变更分支显示“新保留范围 / 将清理的记录数”，主按钮改为“保存并清理”，不显示无关的全部范围选择。
- 提交前计算实际范围，清理中禁止重复点击；零条时主按钮禁用。完成保留筛选并刷新列表。

## D11

**导出脱敏诊断**

来自 [S03](settings-and-system.md#s03)。导出为本地文件，不自动发送给任何人。

```text
+------------------------------------------------------------------------------------+
| 导出诊断信息                                                              [ X ]    |
+------------------------------------------------------------------------------------+
| 导出内容                                                                           |
| [x] 应用版本和平台信息                                                             |
| [x] 服务与连接状态摘要                                                             |
| [x] 最近错误的脱敏代码和请求标识                                                   |
|                                                                                    |
| 不包含：登录凭据、客户端密钥、请求正文、模型正文或工具参数。                       |
| 账号标签、具体 IP、个人路径在导出时移除或替换。                                    |
|                                                                                    |
| 范围 [ 最近 24 小时 v ]                                                            |
|                                                                                    |
| [ 取消 ]                                        [ 选择保存位置并导出 ]             |
+------------------------------------------------------------------------------------+
```

- 内容勾选项用于展示固定包含类别，首版为只读，不暗示可导出敏感字段。
- 打开操作系统保存对话框；取消选择不写文件。导出失败显示原因，保持可重试。
- 导出成功同窗显示文件名与“打开所在目录”，不上传、不复制文件内容到剪贴板。
- 完整导出内容需按 A30 验证，不能只凭文件名写了“脱敏”就称安全。

## D12

**离开未完成操作**

设置草稿离开、测试中的抽屉关闭等共用轻量确认结构。

```text
+------------------------------------------------------------------------------+
| 更改尚未保存                                                                 |
+------------------------------------------------------------------------------+
| 这页设置有未保存的更改。                                                     |
|                                                                              |
| 继续编辑，或者放弃本页更改后离开。                                           |
|                                                                              |
| [ 继续编辑 ]                                            [ 放弃并离开 ]       |
+------------------------------------------------------------------------------+
```

- Esc 与继续编辑一致；放弃只丢弃页面草稿，不改变已保存配置。
- 如果是正在执行模型测试，标题改为“测试仍在进行”，正文说明关闭会取消测试；按钮为“继续查看 / 取消测试并关闭”。
- 已提交的密钥撤销、退出、删除、停止等操作不因遮罩关闭而撤销；执行期间保持状态可见。

## E01

**概览 / 尚未配置**

首次选择稍后设置、或当前没有可用活动连接时的概览。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 概览                                       [ 启动服务 (禁用) ]        |
|                  |                                                                       |
| > 概览           | 完成设置后，其他 Agent 就可以连接模型。                               |
|   账号连接       |                                                                       |
|   模型           | 1. [--] 连接 ChatGPT                      [ 连接账号 ]                |
|   客户端接入     | 2. [--] 选择模型并测试                    [ 尚不可用 ]                |
|   请求记录       | 3. [--] 选择访问地址                      [ 配置网络 ]                |
|   设置           | 4. [--] 创建客户端密钥                    [ 创建密钥 ]                |
|                  |                                                                       |
|                  | 目前没有模型请求记录。                                                |
|                  |                                                                       |
|                  | 随时可以从这里继续设置。                                              |
|                  | 已经保存的步骤会保留。                                                |
+------------------------------------------------------------------------------------------+
| 服务：停止 | 账号：未连接 | 尚未设置监听地址                                             |
+------------------------------------------------------------------------------------------+
```

- 连接账号 [W02](onboarding.md#w02)，配置网络 [W06](onboarding.md#w06)/[D07](#d07)，密钥 [D01](#d01)。向导是推荐顺序，已保存步骤不被重置。
- 尚未测试不是运行时永远禁止启动的条件：至少需可调用账号、有效监听配置和一把有效密钥才解锁启动；向导仍推荐先测试。
- 已有连接仅需重登时将第一步替换为恢复连接，不让用户重新创建所有密钥。

## E02

**列表通用状态组件**

各列表页保留自己的标题、导航和操作栏，内容区使用以下互斥状态。

```text
+------------------------------------------------------------------------------------------+
| 加载中                                                                                   |
+------------------------------------------------------------------------------------------+
| [..] 正在读取模型目录...                                                                 |
| [----------------------------------------]                                               |
| [----------------------------------------]                                               |
|                                                                                          |
| 没有数据                                                                                 |
+------------------------------------------------------------------------------------------+
| 尚未同步模型。                                                                           |
| [ 同步模型目录 ]                                                                         |
|                                                                                          |
| 筛选无结果                                                                               |
+------------------------------------------------------------------------------------------+
| 没有匹配当前筛选的记录。                                                                 |
| [ 清除筛选 ]                                                                             |
|                                                                                          |
| 加载失败                                                                                 |
+------------------------------------------------------------------------------------------+
| [!] 暂时无法读取模型目录。已有缓存仍可查看，但权限待复核。                               |

```

- 这是四个组件样例，不在实际页面同时堆叠展示；具体文案与 CTA 由入口索引的状态矩阵给出。
- 后台刷新已有列表时保留旧内容和时间标记；初次加载才显示占位。
- 无权限不是空列表，必须提示授权恢复；没有匹配项与尚未有数据不能使用同一句文案。

## E03

```text
|   设置           | 已保存配置：192.168.50.10:8787                                        |
|                  |                                                                       |
|                  | [ 修改地址或端口 ]                        [ 重试启动 ]                |
|                  |                                                                       |
|                  | 如果你释放了原端口，可以重试。                                        |
|                  | 修改端口后，需要在客户端同步更新地址。                                |
```

## E04

**服务运行，但账号需要处理**

HTTP 服务仍运行；上游问题不要求用户重新配置客户端地址。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 概览                                          [ 停止服务 ]            |
|                  |                                                                       |
| > 概览           | 服务：[OK] 运行中                                                     |
```
