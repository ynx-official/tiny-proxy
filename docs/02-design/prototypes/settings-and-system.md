# 设置与桌面系统界面

状态：Review  
最后更新：2026-10-13  
关联文档：[原型入口与覆盖表](../ascii-prototype.md)、[桌面流程](../desktop-flows.md)

S01—S05 是设置与只读说明；T01—T04 覆盖托盘、关窗提示、启动和启动受阻。设置中的数值仍为待评审默认值。

[返回原型总览](../ascii-prototype.md)

## S01

**设置 / 常规**

设置有四个二级标签。其他更改先形成草稿，点击保存后生效。2026-10-13 新增的外观主题独立即时保存，提供“跟随电脑 / 白天模式 / 夜间模式”，默认跟随电脑；以 [主题交互](../visual-system.md#白天模式与跟随电脑) 为准，原型中的其他设置不据此视为已实现。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 设置                                                                  |
|                  | [ 常规 ]  [ 请求限制 ]  [ 数据与隐私 ]  [ 关于 ]                      |
|   概览           |                                                                       |
|   账号连接       | 启动与后台运行                                                        |
|   模型           |                                                                       |
|   客户端接入     | [ ] 登录 Windows 后启动 Tiny Proxy                                    |
|   请求记录       | [x] 启动应用时自动启动模型服务                                        |
| > 设置           | [ ] 自动启动时收起到托盘                                              |
|                  |                                                                       |
|                  | 关闭窗口时                                                            |
|                  | (*) 收起到托盘并继续运行    ( ) 退出应用                              |
|                  |                                                                       |
|                  | 自启动只在当前 Windows 用户登录后运行。                               |
|                  | 托盘不可用时，不会隐藏仍在运行的服务窗口。                            |
|                  |                                                                       |
|                  | [ 恢复本页默认值 ]                      [ 放弃更改 ] [ 保存 ]         |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 自动启动时收起托盘依赖“登录 Windows 后启动”；未满足时禁用该项并说明。
- 开机自启默认关；2026-10-13 用户要求应用启动时默认启动代理，自动监听默认开启，规则见 [B15](../../01-requirements/business-rules.md)。当前尚无此开关；收起托盘默认值来自待评审 [D09](dialogs-and-states.md#d09)，不视为用户已选择。
- 保存失败保留草稿并显示错误，不出现成功提示；离开未保存页面使用 [D12](dialogs-and-states.md#d12)。
- 常规设置影响后续启动/关窗，不因勾选自动启动而立即启动当前服务。

## S02

**设置 / 请求限制**

初次只展示常用限制，高级限制可展开；图中为展开状态。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 设置                                                                  |
|                  | [ 常规 ]  [ 请求限制 ]  [ 数据与隐私 ]  [ 关于 ]                      |
|   概览           |                                                                       |
|   账号连接       | 同时处理的请求                                                        |
|   模型           | 全局并发          [ 4      ]                                          |
|   客户端接入     | 单个密钥并发      [ 2      ]                                          |
|   请求记录       |                                                                       |
| > 设置           | 等待与超时                                                            |
|                  | 连接上游          [ 15     ] 秒                                       |
|                  | 等待响应头        [ 60     ] 秒                                       |
|                  | 上游无事件        [ 180    ] 秒                                       |
|                  | 请求总时限        [ 15     ] 分钟                                     |
|                  |                                                                       |
|                  | [-] 高级限制                                                          |
|                  | 请求体 [ 不限 ]     单个流事件 [ 1 ] MiB                             |
|                  | 聚合结果 [ 16 ] MiB  每请求缓冲 [ 16 ] MiB                            |
|                  | 下游写阻塞 [ 30 ] 秒                                                  |
|                  |                                                                       |
|                  | 保存后仅用于新请求，进行中的请求保持原限制。                          |
|                  | [ 恢复本页默认值 ]                      [ 放弃更改 ] [ 保存 ]         |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 所有字段有单位，正数/整数按语义校验；单密钥并发不能超过全局。实际工程允许范围需实现阶段固定。
- 单位不只写在 placeholder；无效字段下显示错误并禁止保存。
- 恢复默认只改本页草稿，不会直接提交；降低并发后不取消已有请求，只限制新请求。
- 这里调整传输和资源限制，不伪装成上游 max_tokens 或采样参数。

## S03

**设置 / 数据与隐私**

说明实际保留内容，并提供有明确边界的本地维护操作。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 设置                                                                  |
|                  | [ 常规 ]  [ 请求限制 ]  [ 数据与隐私 ]  [ 关于 ]                      |
|   概览           |                                                                       |
|   账号连接       | 请求记录                                                              |
|   模型           | 保留最多 [ 7     ] 天                                                 |
|   客户端接入     | 保留最多 [ 10000 ] 条                                                 |
|   请求记录       | 达到任一上限时清理较早记录。                                          |
| > 设置           |                                                                       |
|                  | 保存：时间、模型、客户端、状态、延迟和可用的使用量。                  |
|                  | 不保存：提示词、模型正文、工具参数或登录凭据明文。                    |
|                  |                                                                       |
|                  | 本地数据目录                              [ 打开目录 ]                |
|                  | 请求记录                                  [ 清理记录... ]             |
|                  | 诊断信息                                  [ 导出脱敏诊断... ]         |
|                  |                                                                       |
|                  | 清理请求记录不会撤销密钥或退出账号。                                  |
|                  | 这是本地逻辑删除，不能保证清除备份中的历史数据。                      |
|                  |                                                                       |
|                  | [ 放弃更改 ]                                            [ 保存 ]      |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 清理 [D10](dialogs-and-states.md#d10)，导出 [D11](dialogs-and-states.md#d11)；打开目录是系统文件管理器交接，不属于应用内新页面。
- 减少保留范围后可能立即删除较旧记录，保存前复用 [D10](dialogs-and-states.md#d10) 的影响确认，再提交设置和清理。
- 未实现全库加密，不在 UI 宣称“所有数据都已加密”；登录凭据保护独立说明。
- 不添加导出 Token、导出原始请求或一键清空全部应用数据按钮。

## S05

**内置说明 / 阅读窗**

只读帮助窗口，可从模型测试或设置打开。标签切换只换说明内容。

```text
+------------------------------------------------------------------------------------------+
| 使用说明                                                                  [ 关闭 ]       |
+------------------------------------------------------------------------------------------+
| [ 接入说明 ]  [ 接口支持范围 ]  [ 隐私说明 ]  [ 开源许可 ]                               |
|                                                                                          |
| 接口支持范围                                                                             |
|                                                                                          |
| GET   /v1/models                    活动账号可用模型                                     |
| POST  /v1/chat/completions           文本和函数工具，流式/非流式                         |
| POST  /v1/responses                  明确的 Responses 兼容子集                           |
|                                                                                          |
| 每个接口都需要网关密钥。                                                                 |
| 工具由客户端执行；请求必须带齐所需历史。                                                 |
| 不支持的参数会明确报错，不会默默忽略。                                                   |
|                                                                                          |
| [+] 查看字段与错误说明                                                                   |
|                                                                                          |
| 遇到问题？ [ 返回客户端接入 ]                                                            |
+------------------------------------------------------------------------------------------+
| 文档随应用版本发布。                                                                     |
+------------------------------------------------------------------------------------------+
```

- 接入说明标签展示 [P08](main-pages.md#p08) 的连接步骤和术语说明，不创建第二套接入配置。
- 隐私说明标签展示 [S03](#s03) 的数据类别、保留与删除说明；开源许可标签呈现随安装包附带的真实许可证及依赖条目，长内容滚动阅读。
- 这四项是同一只读文档阅读器的内容，不新增设置或网络权限；正文由当前版本的文档提供，不硬编码在原型里。
- 返回客户端接入关闭阅读窗并选中 [P08](main-pages.md#p08)；Esc 或关闭回到原来源页。

## T01

**托盘菜单**

无主窗口时仍可查看状态和结束服务；系统托盘图标旁的右键菜单。

```text
+--------------------------------------------------+
| Tiny Proxy                                       |
+--------------------------------------------------+
| 服务：运行中                                     |
| 账号：可调用                                     |
| 进行中请求：2                                    |
+--------------------------------------------------+
| 显示主窗口                                       |
| 打开客户端接入                                   |
| 复制 Base URL                                    |
| 停止服务...                                      |
+--------------------------------------------------+
| 退出 Tiny Proxy...                               |
+--------------------------------------------------+
```

- 显示主窗口恢复原页面；接入打开 [P06](main-pages.md#p06)；复制仅服务已监听时启用。
- 停止打开 [D08](dialogs-and-states.md#d08)，退出打开 [D09](dialogs-and-states.md#d09)；服务停止时菜单变为“启动服务”。
- 启动失败要恢复主窗口展示 [E03](dialogs-and-states.md#e03)，不能只留一个无说明的托盘图标。

## T02

**首次关闭窗口 / 托盘提示**

托盘已成功建立且用户设置为收起时，关窗后显示一次提示。

```text
+------------------------------------------------------------------+
| Tiny Proxy 仍在运行                                      [ X ]   |
+------------------------------------------------------------------+
| 模型服务继续接受请求。                                           |
| 你可以从系统托盘恢复窗口或退出应用。                             |
|                                                                  |
| [ 显示窗口 ]                              [ 不再提示 ]           |
+------------------------------------------------------------------+
```

- 这是状态提示，不需要用户重复确认常规关窗。主窗口已收起，服务不被暂停。
- 不再提示仅关闭这类提示，不关闭服务。
- 托盘创建失败时保持主窗口可见，并提示“无法收起到托盘”；不会留下用户找不到的后台服务。

## T03

**启动 / 正在恢复本地状态**

主界面数据尚未就绪的短暂启动窗口，不显示虚假的已登录或已监听。

```text
+--------------------------------------------------------------------------+
| Tiny Proxy                                                               |
+--------------------------------------------------------------------------+
| [..] 正在打开本地数据                                                    |
|                                                                          |
| [OK] 已确认只有一个应用实例                                              |
| [..] 正在检查配置版本                                                    |
| [--] 恢复账号状态                                                        |
| [--] 初始化桌面                                                          |
|                                                                          |
| 正在处理本地数据，请稍候。                                               |
|                                                                          |
| [ 退出 ]                                                                 |
+--------------------------------------------------------------------------+
```

- 成功恢复后进入上次页面或 [W01](onboarding.md#w01)；自动启动服务按 [B15](../../01-requirements/business-rules.md) 的默认开启规则执行。
- 迁移执行时退出操作显示“完成当前本地操作后退出”，不能在不可安全中断的事务内直接杀进程。
- 第二实例只唤起已有窗口，不显示第二个独立运行状态。

## T04

**启动受阻 / 本地数据问题**

数据库过新、迁移失败、凭据保护不可用或数据访问失败。

```text
+----------------------------------------------------------------------------------+
| Tiny Proxy 无法完成启动                                                          |
+----------------------------------------------------------------------------------+
| [!] 本地数据版本高于当前应用支持的版本。                                         |
|                                                                                  |
| 已有数据保持原状，服务尚未启动。                                                 |
| 请使用支持该数据版本的应用，或查看恢复说明。                                     |
|                                                                                  |
| [ 打开数据目录 ]   [ 复制脱敏错误摘要 ]   [ 查看恢复说明 ]                       |
|                                                                                  |
| [ 重试 ]                                                     [ 退出应用 ]        |
+----------------------------------------------------------------------------------+
```

- 迁移失败时替换为迁移失败说明；禁止提供默认清空/重建数据库的按钮。
- 只有某个连接无法解密且其余配置可用时允许进入应用，将该连接标为需重新登录；不把整库失败降级为空配置。
- 该屏用于可渲染窗口的启动错误；若图形初始化本身失败，提供同内容的系统错误对话框，不承诺 GPUI 自身一定能显示。
