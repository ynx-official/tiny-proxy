# 主页面与详情

状态：Review  
最后更新：2026-10-13  
关联文档：[原型入口与覆盖表](../ascii-prototype.md)、[桌面流程](../desktop-flows.md)

P01—P11 覆盖五个日常业务主页面及其详情、接入标签。第六个主页面“设置”见 [设置与系统界面](settings-and-system.md)。公共侧栏在每张主页面上保持一致。

## P01

**概览 / 服务运行中**

日常进入应用的默认页。状态与数字都是原型示例。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 概览                                         [ 停止服务 ]             |
|                  |                                                                       |
| > 概览           | 服务：运行中                 上游账号：可调用                         |
|   账号连接       | 个人连接 A                   [ 管理连接 ]                             |
|   模型           |                                                                       |
|   客户端接入     | 访问地址                                                              |
|   请求记录       | http://192.168.50.10:8787/v1                   [ 复制 ]               |
|   设置           | 局域网 / 以太网                              [ 配置接入 ]             |
|                  |                                                                       |
|                  | 当前请求 2 / 4               有效客户端密钥 2                         |
|                  | 本次运行：完成 18  |  失败 1  |  取消 0                               |
|                  |                                                                       |
|                  | 最近请求                                      [ 查看全部 ]            |
|                  | 时间    客户端          模型          结果                            |
|                  | 14:32   Trae - 笔记本    <model-id>    接收中                         |
|                  | 14:31   其他 Agent      <model-id>    完成                            |
|                  | 14:28   Trae - 笔记本    <model-id>    失败 [ 详情 ]                  |
|                  |                                                                       |
|                  | 接入另一台设备？                              [ 接入指引 ]            |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 停止打开 [D08](dialogs-and-states.md#d08)；管理连接进入 [P02](#p02)；配置接入进入 [P06](#p06)；接入指引进入 [P08](#p08)；详情打开 [P11](#p11)。
- 顶部始终分别显示服务与账号状态。运行中但上游失效时，只替换账号状态与恢复入口，不把服务写成停止。
- 统计限定“本次运行”，重启后重置；请求总量和 quota 不混淆。未返回 usage 显示未知。
- 未配置/停止/失败的概览变体见 [E01](dialogs-and-states.md#e01)、[E03](dialogs-and-states.md#e03)、[E04](dialogs-and-states.md#e04)。

## P02

**账号连接 / 列表**

管理本人保存的账号与工作区注册；一次只选择一个活动连接。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 账号连接                                      [ 添加连接 ]            |
|                  |                                                                       |
|   概览           | 新请求使用：个人连接 A                                                |
| > 账号连接       |                                                                       |
|   模型           | 连接名称          工作区       状态                操作               |
|   客户端接入     | 个人连接 A        个人         可调用 / 当前        [ 详情 ]          |
|   请求记录       | 工作连接 B        工作区 B     可调用        [ 设为当前 ]             |
|   设置           | 旧连接 C          个人         需要重新登录         [ 详情 ]          |
|                  |                                                                       |
|                  | 即使账号相同，不同工作区的连接也分别保存。                            |
|                  |                                                                       |
|                  | 切换后，新请求使用新连接。                                            |
|                  | 已经开始的请求继续使用原连接。                                        |
|                  |                                                                       |
|                  | 模型使用量与授权设置                          [ 前往 ChatGPT ]        |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 添加进入 [W02](onboarding.md#w02)；成功后回本页，选择是否设为当前；不暗中替换已有活动连接。
- 设为当前打开 [D04](dialogs-and-states.md#d04)；详情 [P03](#p03) 包含重新登录、退出及删除入口。
- 无连接使用 [E01](dialogs-and-states.md#e01) 的账号空状态；加载或失败使用 [E02](dialogs-and-states.md#e02)。配额未知不展示进度条。

## P03

**连接详情 / 右侧抽屉**

覆盖在 [P02](#p02) 右侧，列表与滚动位置保留；不新开一级导航。

```text
+--------------------------------------------------------------------------+
| 连接详情                                                        [ X ]    |
+--------------------------------------------------------------------------+
| 个人连接 A（示例）                                                       |
| 工作区：个人                                                             |
| 当前状态：[OK] 可调用                                                    |
| 当前活动连接：是                                                         |
|                                                                          |
| 登录凭据：已安全保存                                                     |
| 访问凭据预计到期：约 45 分钟后                                           |
| 续期：到期前自动尝试                                                     |
|                                                                          |
| 上次模型同步：今天 14:20                                                 |
| 最近一次文本测试：今天 14:21 / 完成                                      |
|                                                                          |
| [ 重新登录 ]                         [ 前往模型列表 ]                    |
|                                                                          |
| 账号操作                                                                 |
| [ 退出此连接 ]                       [ 删除连接... ]                     |
+--------------------------------------------------------------------------+
```

- 重新登录进入 [W02](onboarding.md#w02) 并保留旧连接，成功校验后替换；不是每次刷新目录都登录。
- 退出进入 [D05](dialogs-and-states.md#d05)，删除进入 [D06](dialogs-and-states.md#d06)；模型列表进入 [P04](#p04) 并收起抽屉。
- 续期中显示“正在更新登录凭据”；暂时网络失败显示“暂不可用 / 检查网络”；终态失效显示“需要重新登录”。
- 不展示上游 Token、完整 client_id、subject 或技术 JWT 字段；过期时间不可得时显示未知。

## P04

**模型 / 目录与能力**

只展示当前连接可见模型；此处不提供虚构模型或手工强制开放能力。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 模型                                             [ 刷新目录 ]         |
|                  |                                                                       |
|   概览           | 当前连接：个人连接 A                                                  |
|   账号连接       | 最近同步：今天 14:20                                                  |
| > 模型           |                                                                       |
|   客户端接入     | [ 搜索模型 ID 或名称...                             ]                 |
|   请求记录       | 协议：[ 全部 v ]                                                      |
|   设置           |                                                                       |
|                  | 模型 ID       文本验证        Chat 工具      操作                     |
|                  | <model-id-a>  已通过          已验证         [ 详情 / 测试 ]          |
|                  | <model-id-b>  待测试          待验证         [ 详情 / 测试 ]          |
|                  | <model-id-c>  已通过          不适用         [ 详情 / 测试 ]          |
|                  |                                                                       |
|                  | 可见模型不等于每种协议都可用。                                        |
|                  | 详情中分别列出上游能力、网关支持范围和已验证结果。                    |
|                  |                                                                       |
|                  | 3 个模型                                                              |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 行详情进入 [P05](#p05)；搜索与协议筛选仅本地过滤，不自动调用模型。
- 刷新只同步目录，不发推理；刷新失败可展示标记为旧的缓存，不能标为权限已复核。
- 无权限、未同步、目录空与筛选无结果分别见 [E02](dialogs-and-states.md#e02)；复制 ID 位于详情，不隐式设置客户端模型。

## P05

**模型详情与最小连接测试 / 抽屉**

来自 [P04](#p04)；[W05](onboarding.md#w05) 复用同一测试逻辑。

```text
+--------------------------------------------------------------------------------+
| 模型详情                                                              [ X ]    |
+--------------------------------------------------------------------------------+
| 模型 ID   <model-id>                                             [ 复制 ]      |
| 所属连接  个人连接 A                                                           |
|                                                                                |
| 能力                       声明 / 支持           验证                          |
| 文本                       支持                  本次已完成                    |
| Chat 函数工具              按能力开放            待验证                        |
| Responses 函数工具         按能力开放            待验证                        |
| 图片、文件、音频           首版未开放            --                            |
|                                                                                |
| 连接测试                                                                       |
| 协议  (*) Chat Completions   ( ) Responses                                     |
| 模式  (*) 流式               ( ) 非流式                                        |
|                                                                                |
| 固定测试文本：请简短回复连接测试。                                             |
| [ 开始测试 ]  [ 取消测试 (禁用) ]                                              |
|                                                                                |
| [OK] 本次响应已完整结束                                                        |
| 模型输出（仅本窗口）：连接测试成功。                                           |
| 首段等待 0.8 秒   总耗时 1.2 秒   使用量：未知                                 |
|                                                                                |
| [ 查看接口支持范围 ]                                                           |
+--------------------------------------------------------------------------------+
```

- 这是虚构成功样例；初态显示“尚未测试”，点击后才发一次调用并提示消耗模型额度。
- 测试中禁用切模型/重复开始；取消向下游/上游传播并标记取消，不能显示成功。
- 测试失败显示脱敏原因与重试；抽屉关闭时若有测试，使用 [D12](dialogs-and-states.md#d12) 的“取消测试并关闭”分支。
- 文本测试通过不自动标记工具验证通过；工具状态来自经过验证的协议/模型组合。
- 接口支持范围是本地说明页/折叠区，不加载 Web 管理端。

```text

+------------------------------------------------------------------------------------------+
```

```text
|   账号连接       | 客户端密钥                                  [ 创建密钥 ]              |

| > 客户端接入     |                                                                       |
|   请求记录       | 名称              前缀          状态       最近使用                   |
|   设置           | Trae - 笔记本     key_demo_a    有效       今天 14:32                 |
|                  |                                       [ 请求记录 ] [ 撤销 ]           |

|                  |                                       [ 请求记录 ] [ 撤销 ]           |
```

- 创建 [D01](dialogs-and-states.md#d01) → [D02](dialogs-and-states.md#d02)；撤销 [D03](dialogs-and-states.md#d03)。2026-10-13 按用户要求及 [B20](../../01-requirements/business-rules.md) 改为撤销成功删除列表行及当前明文预览；不展示历史已撤销密钥。
- 请求记录跳 [P10](#p10) 并按 key ID 过滤，返回保留列表位置。

## P09

**连接排查 / 抽屉**

由 [P06](#p06)/[P08](#p08) 的排查入口打开；只检查本应用可观察事实。

```text
+--------------------------------------------------------------------------------+
| 连接排查                                                              [ X ]    |
+--------------------------------------------------------------------------------+
| 本机条件                                                                       |
| [OK] 服务已绑定 192.168.50.10:8787                                             |
| [OK] 选定网卡仍然存在                                                          |
| [OK] 至少存在一把有效客户端密钥                                                |
| [OK] 当前连接允许模型调用                                                      |
|                                                                                |
| 远端条件                                                                       |
| [?] 目标设备路由是否可达：需在目标设备验证                                     |
| [?] 系统防火墙是否放行：尚未确认                                               |
| [?] VPN 两端是否互通：按你的网络配置确认                                       |
|                                                                                |
| 请从目标设备发起请求，并查看此处和请求记录。                                   |
| 只在本机测试成功，不能证明其他设备可达。                                       |
|                                                                                |
| 最近观察：未收到目标密钥的请求                                                 |
|                                                                                |
| [ 刷新本机状态 ]  [ 查看排查说明 ]  [ 打开请求记录 ]                           |
+--------------------------------------------------------------------------------+
```

- 刷新是本机状态读取，不发真实模型推理、不扫描整个局域网。
- 收到鉴权失败只能证明有请求到达，不证明密钥有效；收到请求仍不等于完成推理。
- 本机网络/防火墙无法确认的项目始终用“未知/需验证”，不伪造自动诊断成功。
