# 首次使用与登录向导

状态：Review  
最后更新：2026-10-13  
关联文档：[原型入口与覆盖表](../ascii-prototype.md)、[桌面流程](../desktop-flows.md)

W01—W08 覆盖首次使用及重复登录的共用流程。示例账号、地址、模型、时间和状态均为虚构。

[返回原型总览](../ascii-prototype.md)

## W01

**首次启动 / 欢迎**

首次安装或没有可恢复的连接时出现。独立向导，不显示六项侧栏。

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                        [ _ ] [ [] ] [ X ]     |
+------------------------------------------------------------------------------------------+
| 欢迎使用 Tiny Proxy                                                                      |
|                                                                                          |
| 连接你的 ChatGPT 账号，让自己的 Agent 使用模型。                                         |
|                                                                                          |
| 1. 在浏览器中登录                                                                        |
| 2. 选择模型并测试                                                                        |
| 3. 设置地址与客户端密钥                                                                  |
| 4. 在 Trae 或其他 Agent 中接入                                                           |
|                                                                                          |
| 不需要预先安装 Codex。                                                                   |
|                                                                                          |
| [ Continue with ChatGPT ]                       [ 稍后设置 ]                             |
+------------------------------------------------------------------------------------------+
| 首次设置  1/4：连接账号                                                                  |
+------------------------------------------------------------------------------------------+
```

- 登录进入 [W02](#w02)；稍后设置进入 [P01](main-pages.md#p01) 的未配置状态，服务保持停止。
- 官方登录页面属于系统浏览器，本原型不仿制其账号密码、工作区或同意授权页面。

## W02

**等待浏览器授权**

来自 [W01](#w01)、账号页添加连接或重新登录。重新登录时保留原活动连接。

```text
+------------------------------------------------------------------------------------------+
| 连接 ChatGPT                                                          [ 取消登录 ]       |
+------------------------------------------------------------------------------------------+
| 步骤 1/4：连接账号                                                                       |
|                                                                                          |
| [..] 浏览器已打开，等待你完成登录                                                        |
|                                                                                          |
| 请在官方页面选择账号并确认授权。                                                         |
| 完成后会自动返回此处。                                                                   |
|                                                                                          |
| 剩余时间 09:42  （示例）                                                                 |
|                                                                                          |
| [ 再次打开浏览器 ]                                  [ 取消登录 ]                         |
+------------------------------------------------------------------------------------------+
| 正在为本应用建立连接。                                                                   |
+------------------------------------------------------------------------------------------+
```

- 按钮不复制、显示或记录含敏感登录提示信息的完整授权 URL。
- 回调后在同一页依次显示“正在验证账号”“正在保存连接”，此时重复打开/重复提交禁用。
- 成功进入 [W05](#w05)；无模型权限进入 [W03](#w03)；失败、过期或取消进入 [W04](#w04)。

## W03

**已登录，但未允许模型调用**

身份验证完成，但本应用没有获得模型调用权限。

```text
+------------------------------------------------------------------------------------------+
| 连接账号                                                                                 |
+------------------------------------------------------------------------------------------+
| [!] 账号已登录，还不能调用模型                                                           |
|                                                                                          |
| 连接：个人连接 A（示例）                                                                 |
| 模型调用：未授权                                                                         |
|                                                                                          |
| 允许本应用使用模型后，才能继续测试和接入 Agent。                                         |
|                                                                                          |
| [ 前往授权 ]                              [ 暂不授权，进入应用 ]                         |
+------------------------------------------------------------------------------------------+
| 没有发起模型请求。                                                                       |
+------------------------------------------------------------------------------------------+
```

- 前往授权重新使用当前注册发起 [W02](#w02)，完成后重新检查实际授予权限。
- 暂不授权进入 [P01](main-pages.md#p01)；账号页显示该连接状态，测试模型操作禁用。
- 如果上游明确不支持该账号/工作区，显示具体限制和返回账号页，不能无限循环登录。

## W04

**登录取消、失败或过期**

[W02](#w02) 的可恢复结果页；根据实际原因替换标题和解释。

```text
+------------------------------------------------------------------------------------------+
| 连接未完成                                                                               |
+------------------------------------------------------------------------------------------+
| [!] 本次登录已过期                                                                       |
|                                                                                          |
| 授权未在有效时间内完成，请重新开始。                                                     |
| 之前保存的账号连接未受影响。                                                             |
|                                                                                          |
| [ 重新登录 ]                                   [ 返回 ]                                  |
|                                                                                          |
| 错误摘要：授权已过期                                                                     |
| [ 展开诊断信息 ]                                                                         |
+------------------------------------------------------------------------------------------+
| 诊断信息只显示脱敏错误码与本次请求标识。                                                 |
+------------------------------------------------------------------------------------------+
```

- 取消：标题“已取消登录”，不使用失败警报；拒绝授权：解释由用户拒绝。
- 浏览器未打开：先留在 [W02](#w02) 提供再次打开；本地回调端口或网络异常才进入此结果页。
- 身份不匹配或凭据保存失败：显示相应原因，不出现“登录成功”。返回恢复发起页面。
- 首次向导返回 [W01](#w01)；从账号页发起则返回 [P02](main-pages.md#p02)。

## W05

**选择模型并测试**

登录获得模型权限后，自动拉取目录；这是向导第 2 步。

```text
+------------------------------------------------------------------------------------------+
| 首次设置  2/4：选择模型                                                                  |
+------------------------------------------------------------------------------------------+
| [OK] 个人连接 A 已允许模型调用                                                           |
|                                                                                          |
| 测试模型  [ <model-id>                                          v ]                      |
|                                                                                          |
| 模型目录已同步。                                                                         |
| 兼容性：文本待测试；工具调用待验证。                                                     |
|                                                                                          |
| 点击测试会发送一段固定测试文本，使用当前账号的模型额度。                                 |
| 测试输出只在本次窗口中显示，不保存为请求正文。                                           |
|                                                                                          |
| [ 测试连接 ]                                                                             |
|                                                                                          |
| 测试结果：尚未测试                                                                       |
|                                                                                          |
| [ 上一步 ]                    [ 稍后测试 ]       [ 下一步：网络 (禁用) ]                 |
+------------------------------------------------------------------------------------------+
```

- 测试中原位显示“等待模型/正在接收”，可取消；成功明确显示“模型已完整响应”，下一步解锁。
- 只有完成终态才算通过；不能因出现文字、HTTP 200 或目录成功而点亮通过。
- 失败显示原位原因及重试，不自动循环调用。详细测试交互复用 [P05](main-pages.md#p05)。
- 稍后测试进入概览未完成设置提示；下次从对应步骤继续。模型选择不成为全局默认模型，不覆盖客户端 model。

## W06

**选择访问地址**

向导第 3 步；示例使用局域网，实际首次进入默认选择仅本机。

```text
+------------------------------------------------------------------------------------------+
| 首次设置  3/4：连接你的设备                                                              |
+------------------------------------------------------------------------------------------+
| 哪些设备需要使用这个服务？                                                               |
|                                                                                          |
| ( ) 仅这台电脑       127.0.0.1                                                           |
| (*) 局域网设备       [ 以太网 / 192.168.50.10                  v ]                       |
| ( ) 个人 VPN 设备    [ 选择 VPN 网卡                           v ]                       |
|                                                                                          |
| 端口  [ 8787       ]                                                                     |
|                                                                                          |
| [!] 普通局域网 HTTP 会明文传输内容。                                                     |
|     需要加密连接时，请使用个人 VPN。                                                     |
|                                                                                          |
| 配置摘要：192.168.50.10:8787                                                             |
| 当前尚未启动服务。                                                                       |
|                                                                                          |
| [ 上一步 ]                                  [ 保存并继续：创建密钥 ]                     |
+------------------------------------------------------------------------------------------+
```

- 实际默认选本机，示例星号仅演示已主动选择 LAN 的状态；一次选择一个具体监听地址。
- 下拉只列本机真实存在的 IPv4；无 VPN 网卡时该项禁用并说明“先连接个人 VPN”。
- 端口允许 1—65535，必填且为整数；不能选 0 作为随机端口。占用由启动动作最终判定。
- 继续打开 [D01](dialogs-and-states.md#d01)，然后 [D02](dialogs-and-states.md#d02)；密钥完成后回 [W07](#w07)。编辑值在保存前不影响正在运行的实例。

## W07

**启动前确认**

网络已保存且至少存在一把有效客户端密钥。

```text
+------------------------------------------------------------------------------------------+
| 首次设置  4/4：启动服务                                                                  |
+------------------------------------------------------------------------------------------+
| 账号            个人连接 A                                                               |
| 测试模型        <model-id>       [OK] 文本测试完成                                       |
| 访问方式        局域网                                                                   |
| 监听地址        192.168.50.10:8787                                                       |
| 客户端密钥      Trae - 笔记本    已创建                                                  |
|                                                                                          |
| [ 编辑网络 ]    [ 创建其他密钥 ]                                                         |
|                                                                                          |
| [x] 以后启动应用时，自动启动服务                                                         |
|                                                                                          |
| 关闭窗口默认收起到托盘；退出应用会停止服务。                                             |
|                                                                                          |
| [ 上一步 ]                                         [ 启动服务 ]                          |
+------------------------------------------------------------------------------------------+
```

- 启动中禁用重复操作，显示实际绑定进度；成功才进入 [W08](#w08)。
- 绑定失败保留配置并显示 [E03](dialogs-and-states.md#e03)，不偷偷换端口。
- 2026-10-13 用户要求应用启动时默认启动代理；此项改为默认勾选，前提及行为以 [B15](../../01-requirements/business-rules.md) 为准。当前实现固定默认开启，开关仍属原型；窗口关闭行为仍属原方案待评审默认值。

## W08

**完成设置 / 首个客户端接入**

服务已实际监听，展示可复制的真实地址；不是外部设备可达的保证。

```text
+------------------------------------------------------------------------------------------+
| 服务已启动                                                                               |
+------------------------------------------------------------------------------------------+
| [OK] 正在监听 192.168.50.10:8787                                                         |
|                                                                                          |
| 在 Trae 中选择：OpenAI Chat Completions                                                  |
|                                                                                          |
| Base URL                                                                                 |
| http://192.168.50.10:8787/v1                                 [ 复制 ]                    |
|                                                                                          |
| 模型 ID   <model-id>                                       [ 复制 ]                      |
| API 密钥  使用刚才创建时保存的密钥；这里不再展示。                                       |
|                                                                                          |
| 还没有观察到这个客户端的有效请求。                                                       |
| 在客户端发送一条消息后，可在请求记录中查看结果。                                         |
|                                                                                          |
| [ 查看详细接入步骤 ]                               [ 进入概览 ]                          |
+------------------------------------------------------------------------------------------+
```

- 详细步骤进入 [P08](main-pages.md#p08)；概览进入 [P01](main-pages.md#p01)。丢失密钥时进入 [P07](main-pages.md#p07) 重新创建，不能从摘要恢复。
- 收到某密钥的鉴权通过请求后，只显示“已收到请求”；只有正常终态才显示“最近调用完成”。
- 地址复制不包括密钥。跨设备验证由实际目标设备发请求完成。



## 认证路线修订（2026-10-13）

ADR 0003 已替代本原型中的 SIWC 注册与回调语义。W01 的入口为“使用 Codex 设备码登录”；W02 显示一次性设备码、复制按钮、打开 https://auth.openai.com/codex/device、等待/取消/超时状态。代码由本人在浏览器输入，应用轮询交换 Token，无 loopback 回调。W03 不再表示 SIWC scope 授予；Codex 账号或模型限制按实际模型请求错误展示。其余向导是完整产品目标，当前切片从账号、模型、客户端接入三个页面完成流程。
