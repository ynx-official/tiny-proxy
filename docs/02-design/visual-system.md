## 白天模式与跟随电脑

2026-10-13 用户明确要求增加白天模式、默认跟随电脑，因此替代原“仅深色”规则。HashiCorp 源参考只有深色营销配色；浅色为本项目的桌面适配，保持现有布局、字体、间距与分层关系，不更换 Style ID。

| 颜色角色 | 白天 | 夜间 |
|---|---|---|
| 画布 / 面板 | #f7f8fa / #ffffff | #000000 / #15181e |
| 正文 / 次要文字 | #15181e / #525b69 | #ffffff / #b2b6bd |
| 分隔边框 | #cdd2da | #3b3d45 |
| 成功 / 警告 / 错误文字 | #006e4f / #916000 / #c22b36 | #00ca8e / #ffcf25 / #f24c53 |
| 焦点 / 链接 | #1766cf | #2b89ff |

设置页的“外观主题”提供“跟随电脑 / 白天模式 / 夜间模式”。新安装和旧库升级均默认跟随电脑的应用主题；Windows 的系统模式与应用模式分开设置时，以应用模式为准。运行期间系统外观变化立即重新解析“跟随电脑”；固定模式保留手动选择。重新选择“跟随电脑”使用电脑此时的主题。

点击选项后，由后台提交 SQLite 偏好，成功后刷新页面、按钮、输入框、状态文字和滚动条；保存期间禁用重复选择。保存失败或命令发送失败时保留原主题并显示错误。重启恢复的是偏好值 system/light/dark，不能把当时解析出的颜色模式保存成固定模式。主题切换不修改监听、账号或在途请求。

测试清单及未运行事项见 [主题验证清单](../04-quality/theme-checklist.md)；实现与运行证据见 [开发验证记录](../06-delivery/implementation-status.md)。

原参考是营销页面，以下是保持产品可用性的桌面适配：标题 22–28px，正文 14–16px，导航与表格紧凑排列，不搬入 80px 营销标题、96px 大段落间距或产品宣传卡。系统 Segoe UI / Microsoft YaHei UI 字体替代专有字体；API 地址可用等宽字体。圆角控件 8px，间距采用 4/8/12/16/24/32。

不使用 HashiCorp 商标、专有字体或产品名称。颜色用于 Tiny Proxy 的状态，不把其他产品配色当作装饰。低对比的 #656a76 不用于必读提示。所有操作保留 GPUI Kit 的键盘焦点和禁用反馈。

当前仅决定视觉规则；实际窗口、IME、DPI、键盘与溢出检查在实施证据中分别记录。
