## 白天模式与跟随电脑

### 实际截图偏差纠正（2026-10-14）

用户实际截图显示侧栏垂直居中、字体/控件偏小、表格列与页头操作位置偏离预览，并且品牌位误用了通用网络图标。上轮仅执行源码检查，没有发现这些实际问题，不能作为视觉完成依据。本轮源码纠正如下：

- 工作区与双栏抽屉显式使用交叉轴拉伸，侧栏 `self_stretch()`，避免 GPUI `h_flex()` 默认垂直居中。侧栏直接从导航开始，移除预览中没有的额外品牌块。
- Root 的 rem 基准由 14 改为 16px；正文 15px、辅助 14px、标题 26px、导航 16px/图标 20px。按钮 36px、表单输入 40px，避免 rem 与小字号重复缩小。
- 窗口沿用现有 ICO；内部品牌图片内嵌 `assets/icons/png/tiny-proxy-128.png`，设置“关于”展示同一素材，不依赖旁置文件，不使用生图中的临时 logo。
- 页头动作右对齐；概览突出地址/复制，统计居中分列，最近请求标题在表格内部，默认四条；压缩多余段落和重复底部状态栏。
- 表头、数据与操作列共用最小宽度和增长比例；接入/请求使用下划线标签，接入改为有竖分隔的平面双栏及可展开选择器，账号额度横向排布。
- 请求抽屉宽 440px，时间线使用紧凑行与连续节点；展示简要 HTTP/用量，完整字段按需展开，复制始终保留完整数据。异常列表用简短结果，代码/安全原因在详情查看，跨页未加载信息写明“见明细”。
- 模型与设置统一尺寸；测试历史按需展开，设置按外观/更新与应用信息分栏。实际窗口、DPI 和交互仍待 [逐页验收](../04-quality/desktop-redesign-checklist.md)，不因源码修改而标记通过。

### 按钮与基础交互统一（2026-10-14）

- 常规按钮共用 36px 高度、14px 水平内边距；输入/授权按钮 40px、导航 44px。页面主操作共用动作按钮工厂：白天白底边框，夜间白底黑字；链接/标签使用现有轻量样式，撤销最终确认使用危险语义，状态绿色不用于动作按钮。
- 概览、账号停止入口和客户端接入共用服务控件，按真实监听状态显示“启动服务 / 停止服务”。启动采用当前监听配置，启动时恢复上次保存值，空配置为 127.0.0.1:8787；仅成功监听后保存。账号/密钥不足有禁用原因及对应配置入口。模型测试期间仍可停止已有服务。
- 启停、密钥创建/读取/撤销、账号切换、额度刷新、模型刷新/测试、分页和更新配置/检查/下载/安装使用本地等待状态，入队成功后拦截重复提交，对应回执或错误后恢复；不根据点击伪造业务成功。停止已停止的服务也回传停止状态，便于幂等恢复。
- 登录取消按钮、关闭按钮与 Escape 共用取消流程；仅保留一个可重复打开的授权页面按钮。设备码过期取消等待并保留重试。选择器互斥展开，切页和 Escape 收起；Escape 同时取消密钥撤销确认和隐藏明文。
- 密钥名校验与存储规则一致（trim 后 1–80 字符，无控制字符）。切页/隐藏后迟到的创建或读取回执不再显示明文，复制仅响应用户已发起的复制动作。完整删除以已提交的密钥快照为准。
- 请求详情保留按 ID 隔离、加载、关闭和复制；分页仅匹配目标页的回执解除等待。设置保存/更新等待时禁用重复操作，安装保留确认/稍后安装及 Escape；全页错误提示可关闭，关闭提示不删除诊断记录。

## 页面重构规则（2026-10-14）

- 六项导航共用左侧栏、页头、轻分隔、真实服务/账号状态栏和短暂复制反馈。概览突出实际监听地址、放大趋势图与真实统计，不再显示最近请求；左侧按最新批准图分组，原跳转目标不变。
- 预览中的“本次完成”“当前账号可调用”不能由凭据快照推导。首页改用[独立统计查询](overview-statistics.md)，按实际生成请求结果、用量与观察时间计算，不再显示原“本页生成中/已保存请求/失败异常/有效密钥”四项；账号状态仍为“已登录/凭据已保存”，不等同于调用验证通过。
- 账号列表与额度使用真实账号快照。未知或越界额度显示未提供，不画假进度；设备码授权使用右侧抽屉和后台真实到期时间。沿用添加/切换账号前停止网关的现有限制。
- 客户端接入分为连接地址、客户端密钥、接入指南。地址仅在监听成功后可复制，模型来自当前目录；密钥仍经应用服务查看/复制，保留两分钟隐藏、撤销确认与撤销即删除。
- 请求/失败分页保持每页 100 条，搜索明确限于本页元数据。详情抽屉按请求 ID 读取，展示观察到的时间线、安全异常和完整元数据；复制按面板顺序包含同一快照，不补采正文、不自动重放请求。
- 运行中的请求不伪造结束，缺失首个输出保持未知；恢复确认不充当真实结束，HTTP 200 不等于流完整结束。
- 删除首页最近请求后的初始窗口布局尺寸恢复为1280×820、最小960×640；宽度不足1180时，详情覆盖内容区。页面与抽屉分别滚动，宽表格可横向滚动，长地址在复制时保留完整值。Escape 可收起请求详情，或取消并关闭登录抽屉。键盘焦点与 DPI 效果仍需实机验收。

设置页的“外观主题”提供“跟随电脑 / 白天模式 / 夜间模式”。新安装和旧库升级均默认跟随电脑的应用主题；Windows 的系统模式与应用模式分开设置时，以应用模式为准。运行期间系统外观变化立即重新解析“跟随电脑”；固定模式保留手动选择。重新选择“跟随电脑”使用电脑此时的主题。

点击选项后，由后台提交 SQLite 偏好，成功后刷新页面、按钮、输入框、状态文字和滚动条；保存期间禁用重复选择。保存失败或命令发送失败时保留原主题并显示错误。重启恢复的是偏好值 system/light/dark，不能把当时解析出的颜色模式保存成固定模式。主题切换不修改监听、账号或在途请求。
