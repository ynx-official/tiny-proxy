## 本轮交付

45 幅编号 ASCII 布局：公共壳 1 幅，向导 8 幅，主页面与详情 11 幅，设置与系统 9 幅，弹窗与状态 16 幅。覆盖全部六个主导航页面，并为每个操作提供入口、结果和返回路径。

这是布局与交互原型，不是运行界面；所有账号、IP、密钥前缀、模型 ID、时间、统计与结果均为示例。角括号表示运行时值，绝不是已存在的模型/账号或真实密钥。

边框与控件标记使用 ASCII，内容用中文。按中文双宽字符做等宽对齐；阅读时使用支持中英文等宽显示的字体。界面色彩、字体、图标和品牌风格仍待选择，未默认为某个 Style ID。

既有需求与 API 文档仍是业务规则的权威来源；原型新增的操作细节是 Review 建议，不能反过来当成已批准需求。

## G01

**全局应用壳 / 概览示意**

```text
+------------------------------------------------------------------------------------------+
| Tiny Proxy                                                  [ _ ] [ [] ] [ X ]           |
+------------------------------------------------------------------------------------------+
| 导航             | 概览                                         [ 停止服务 ]             |
|                  |                                                                       |
| > 概览           | 服务：运行中             账号：个人连接 A / 可调用                    |
|   账号连接       |                                                                       |
|   模型           | 访问地址                                                              |
|   客户端接入     | http://192.168.50.10:8787/v1                  [ 复制 ]                |
|   请求记录       | [ 配置客户端接入 ]                                                    |
|   设置           |                                                                       |
|                  | 当前请求 2 / 4           最近调用：完成                               |
|                  |                                                                       |
|                  | 最近请求                                                              |
|                  | 时间     客户端           状态                                        |
|                  | 14:32    Trae - 笔记本     接收中                                     |
|                  | 14:31    其他 Agent       完成                                        |
|                  |                                                                       |
|                  | [ 查看全部请求 ]                                                      |
+------------------------------------------------------------------------------------------+
| 服务：运行中 | 账号：可调用 | 地址：192.168.50.10:8787                                   |
+------------------------------------------------------------------------------------------+
```

- 固定六项导航：概览、账号连接、模型、客户端接入、请求记录、设置。
- 顶部保留系统窗口操作；底部状态栏始终区分服务、账号、实际监听地址。
- 原型建议常用窗口约 1120×760；内容过长时主区域独立滚动。小窗口优先保留功能，表格可横向滚动，不把按钮挤到窗外。尺寸尚未实机验证。
- 抽屉覆盖内容右侧，保留列表和筛选；弹窗只处理明确的短操作。
- 每页一个主要动作：启动/停止、添加连接、刷新目录、创建密钥、筛选请求或保存设置。
- 无聊天输入框和 Agent 工作区。模型测试使用固定文本，不让工具窗口变成聊天产品。

               |                                  |

                                                  |

                                                        |
                                                        v
日常使用                                              P01 概览
  +-- P02 账号连接 -> P03 详情 -> 切换/重登/退出/删除
  +-- P04 模型 -> P05 详情/测试
  +-- P06 连接地址 <-> P07 密钥 <-> P08 接入指南
  |                  |                |
  |                  +-> D01/D02      +-> P09 排查
  +-- P10 请求记录 -> P11 请求详情
  +-- S01 常规 <-> S02 限制 <-> S03 隐私 <-> S04 关于
                                                  |
                                                  +-> S05 只读说明

应用启动 -> T03 恢复 -> 上次页面 / W01

官方浏览器登录、Windows 文件保存/文件管理器和安装器是外部系统界面；本原型覆盖交接入口、等待、取消和回到应用，不仿造其内部页面。

## 六个主页面的状态覆盖

| 页面 | 首次/无数据 | 加载/保存中 | 错误/不可用 | 成功/正常 |
|---|---|---|---|---|
| 概览 P01 | E01 分步恢复入口 | 启动中按钮禁用，等待真实监听 | E03 服务错误；E04 账号问题 | 服务、账号与请求结果分别显示 |
| 账号 P02 | 无连接 + 添加连接 | 加载列表；W02 授权；P03 续期状态 | W03 权限不足；W04 登录失败；P03 需重登 | 当前连接、切换、详情 |
| 模型 P04 | 未同步 + 同步；目录为空解释权限 | 初次 E02；后台刷新保留旧目录 | 错误与缓存过期标记；账号恢复入口 | 列表、筛选、P05 测试结果 |
| 接入 P06—P08 | 无配置进入 W06；无密钥创建 D01 | 启动、重启、密钥提交各自禁用重复点击 | E03、P09、D03 操作错误 | 地址复制、密钥管理、接入说明 |
| 请求 P10 | 无记录 + 接入指南；无匹配 + 清筛选 | 首次占位；后台新记录不抢焦点 | 读取失败 + 重试；P11 各种终态 | 分页、筛选、详情、清理 |
| 设置 S01—S04 | 显示已记录的默认值 | 保存中禁用重复提交 | 字段内校验；保存失败保留草稿 | 保存结果明确；离开脏表单 D12 |

“无数据”和“筛选无结果”必须区分；“登录成功”和“有模型权限”必须区分；模型列表可见和某协议实际通过必须区分。所有默认数值来自业务规则，仍保持其评审状态。

## 控件与操作约定

| 表达 | 含义 / 行为 |
|---|---|
| [ 按钮 ] | 明确可点击动作；标注禁用时不得触发 |
| [ 输入值 ]、[ 选项 v ] | 文本/数值输入、下拉 |
| [x] / [ ] | 复选框；诊断包含项特例为只读并注明 |
| (*) / ( ) | 单选项；示例选择不等于产品初始默认 |
| [OK] / [!] / [..] / [--] / [?] | 完成、需处理、进行中、未开始/不适用、未知；实际 UI 需文字并列 |
| 复制 | 只复制该字段；成功提示“已复制”；失败给重试，不擅自转写其他位置 |
| X / Esc | 普通抽屉回来源；脏草稿/进行中测试先 D12；不可误关密钥唯一展示页 |
| 保存 | 校验后提交，成功才离开保存中；失败保留草稿 |
| 重试 | 只重试本次明确操作；不重放失败模型请求，不自动重复工具调用 |
| Tab / Shift+Tab | 顺序聚焦控件；弹窗焦点约束，关闭后回发起按钮 |
| Enter | 表单默认安全动作；撤销/删除等破坏动作不因回车误触 |
| 继续浏览 | 普通后台加载不阻塞导航；取消/关闭结果必须可解释 |

操作提交的 loading、成功、失败都应由真实后台状态驱动。不能用定时器模拟成功，也不能单靠颜色表达可用性。

## 需要在原型评审中确定的细节

1. 首次向导可稍后设置，返回概览逐步恢复；日常不强迫重复向导。
2. 建议启动前至少检查可调用账号、有效监听配置和有效密钥；模型测试推荐但不作为日常启动的永久门槛。已经运行的服务遇到账号失效时继续监听并报上游错误。
3. 网络运行中修改采用“保存并重启”并说明在途影响；绑定失败保持停止，让用户修正。
4. 设置采用显式保存；保留时间缩短会清理记录，保存前确认影响。
5. 关闭窗口入托盘、默认数值、日志/删除规则仍沿用原方案的 Review 状态。
6. Style ID 待高保真阶段选择；本次没有批准认证替代路线或开始开发。

这些是本次把需求变为可操作界面时提出的具体选择，未静默改写已确认范围。

## 文档检查

检查项：45 个界面编号唯一；六个导航和 R01—R12 均有对应布局；按钮引用的界面存在；本地链接与锚点存在；ASCII 框按字符显示宽度对齐；敏感值为占位；不存在业务代码。
