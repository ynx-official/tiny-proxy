## 当前证据

已进行本地源码阅读、官方资料核对、方案文档整理和 [ASCII 原型](../02-design/ascii-prototype.md)设计。原型只做文档结构、覆盖与字符布局检查；没有工程、依赖安装、登录试验、真实模型调用、编译、lint、测试或 UI 运行结果。

实施后每阶段创建日期明确的验证记录，写环境、命令、结果和未通过项；记录放 docs/04-quality/，同步总索引，不上传真实 Token 或提示词。

## TDD 与验证层

| 层 | 验证内容 | 手段 |
|---|---|---|
| 纯协议单测 | 字段映射、SSE、终态、工具 ID、参数增量、使用量 | 合成 fixture、表驱动测试、随机分片/property tests |
| 认证单测 | state/nonce、权限、刷新单飞、轮换失败、退出竞态 | 可控制时钟 + fake OAuth 服务 |
| 存储集成 | 事务、迁移、generation、密钥摘要、清理、锁冲突 | 临时真实 SQLite 文件，不只内存数据库 |
| HTTP 集成 | 真实 socket、流、取消、慢下游、鉴权、错误头 | 本机 fake 上游 + Axum 服务 |
| SDK 契约 | 模型目录、Chat/Responses 流与非流、错误识别 | 固定版本兼容 SDK，作为测试客户端不成为运行依赖 |
| GPUI 集成 | 命令、状态、焦点、加载/错误/空状态 | 锁定 Kit 版本支持的组件测试能力 |
| Windows 实机 | IME、DPI、托盘、浏览器回调、单实例、休眠 | 人工场景与系统/UI 自动化可用部分 |
| 真实接入 | 账号、实际模型、工具往返、LAN/VPN、Trae | 单独 opt-in；不在 CI 自动消费个人额度 |

先写能失败的行为测试并记录失败，再实现，再运行相关测试。Bug 必须有稳定复现的回归测试；不删测试或放宽断言制造通过。

## 流式故障矩阵

对文本、函数调用和混合输出，在每个事件边界及随机字节位置切断；插入延迟、错序、重复快照、无效 JSON、未知语义事件和相矛盾终态。

同时验证编码后的实际 HTTP 字节，不只检查内部 enum。客户端必须能实际逐段读到结果；不能以“返回类型是 Stream”证明没有整段缓冲。

取消要覆盖：等待凭据、等待响应头、接收流、非流式聚合、慢下游、停止服务和密钥撤销。检查上游请求计数与任务/许可归还。

## P0 必需真实证据

- 没有 Codex 的应用目录完成Codex 设备码登录。
- 指定账号可见模型与最小推理 response.completed。
- Codex 平铺 function tools 的真实字段形状及两轮工具结果回传。
- Chat 无私有 reasoning 回放的目标模型适用性。
- GPUI/Kit 匹配版本、中文输入、缩放、托盘、浏览器打开和可执行文件运行。
- 固定 Trae 版本的默认请求参数，特别是采样参数和输出限制。

所有输出只保留允许的脱敏结构；真实回包不得直接作为 fixture 提交。

## 本地性能预算（建议验收目标，非承诺）

| 指标 | 测试方法与初始目标 |
|---|---|
| 取消传播 | fake 上游在客户端断开 2 秒内观察到取消/连接结束 |
| 流式转发开销 | 同机 fake 上游 20 个事件/秒、连续 60 秒；事件从网关收到到测试客户端收到 p95 < 50 ms |
| 有界资源 | 4 并发持续 30 分钟，含慢下游；队列不超过配置预算，RSS 预热后无持续线性增长 |
| UI 响应 | 4 并发流下启停、切页、恢复窗口操作可响应；记录事件处理延迟，目标 p95 < 100 ms |
| 空闲占用 | 记录启动后 5 分钟 CPU/RSS/显存，建立目标硬件基线，再决定发布阈值 |

测试记录必须说明机器、构建模式、模型/fake 服务、采样方式。网络和模型首 token 延迟不计为本地网关开销；不对真实上游承诺 token/s。

## CI 与构建

P1 建立 Windows CI，后续按变更风险运行：

- cargo fmt --check
- cargo clippy --all-targets --locked -- -D warnings
- cargo test --locked
- cargo build --release --locked
- 依赖漏洞/许可检查工具在实施阶段选定并锁定；不无条件自动更新依赖。

GUI 测试按 runner 的图形环境适配，不能直接跳过再称 UI 已验证。涉及平台凭据保护的测试必须在 Windows 上运行。真实账号 Token 不进入 CI secret 或日志。
