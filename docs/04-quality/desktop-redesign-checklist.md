## 构建后桌面检查（全部待验）

2026-10-14 用户要求统一检查所有页面。本轮已逐项核对按钮源码与回执处理并修改下表所列行为；“源码核对”不表示以下操作在实际窗口中已通过。

| 页面 | 源码核对与修改 | 实机需覆盖的状态 |
|---|---|---|
| 概览 | 共用启停、启动失败重试、缺账号/密钥配置入口、地址复制、请求详情/全部入口 | 停止→启动→停止→再启动；端口占用；等待连点；无账号/密钥；模型测试时停止 |
| 账号 | 中性添加、停止入口、切换等待、额度刷新等待、统一授权取消、单一浏览器入口、过期重试 | 服务运行/启动中不可换账号；成功/取消/超时/错误；额度/切换重复点击；Escape |
| 模型 | 目录刷新/指定模型测试等待、复制 ID、用于接入、历史展开 | 刷新/测试失败恢复；切换账号后目录；真实文本测试需另行授权 |
| 客户端 | 共用启停、密钥名校验、创建/查看/复制/隐藏/撤销、互斥选择器和指南返回 | 空名/80/81/控制字符；撤销确认/取消/失败；切页或隐藏后迟到明文；两分钟隐藏 |
| 请求 | 标签/搜索、目标页回执（含数据清理后的页码归一）、详情加载/关闭/迟到隔离、复制/完整字段展开 | 首尾页、快速连点、清理后页码回落、空结果、详情失败重试、Escape；不改变原诊断语义 |
| 设置 | 中性选项、主题保存、更新等待、下载取消/重试、安装确认/稍后/Escape、退出与错误关闭 | 保存失败、更新断网、下载取消后重试、安装确认与异常；真实安装另行授权 |

全页主动作不得再使用绿色实心按钮；白天使用白底边框、灰色 hover/active，夜间保留单色主动作。选择项、文字链接、危险确认按语义区分，所有状态必须可读。

优先逐页与批准预览对照：侧栏必须从顶部铺满工作区；顶部不加品牌块，底部按新图显示自有图标/名称/版本；系统图标和“关于”均使用现有中继之门；字号/行高可读；表头与操作列铺满且对齐；接入和请求标签没有大块填充。首页按最新缓存统计预览检查，初始布局尺寸恢复为1280×820，再检查960×640及不同 DPI。账号选择器/额外额度、模型选择器/测试历史、完整请求字段展开均需操作验证，不能仅凭文档或格式结果打勾。

1. 白天/夜间/跟随电脑各遍历六个页面，页头标题保持横向单行、主操作右对齐，顶部没有逐字换行或大块空白。核对层级、间距、表格、导航、输入/焦点、hover/active/disabled 和复制反馈；保存主题失败保留原选择，重开仍恢复偏好。检查非必要说明段已删除，错误/禁用原因、撤销和安装确认仍可识别。
2. 在 1280×820、960×640、100%/150%/200% DPI 与长账号名/模型名/地址下检查布局。窄窗抽屉覆盖内容区，表格可横向滚动；页面、抽屉滚动互不干扰。检查 Tab/Shift+Tab、抽屉打开/关闭的焦点及 Escape；需要时补齐焦点限制。
3. 概览无账号/无密钥/未监听/监听中分别正确展示；未知模型能力不宣称可调用，统计明确范围，不出现演示账号、设备码和硬编码业务数字。
4. 账号授权申请、等待、剩余时间、复制、重新打开浏览器、取消/超时/失败重试均能恢复；关闭或 Escape 取消本次授权，已有账号保留。服务运行时添加/切换禁用，停止后恢复。真实登录需本人操作。
5. 所有账号额度按真实快照展示；未知、0%、100%、异常和上次成功保留均合理，刷新使用对应账号。主题切换不重新查询或改变后台频率。
6. 客户端三个标签可切换；未监听不能复制地址，监听后完整地址/模型 ID 复制正确；用于接入仅选择现有模型。逐把查看/复制/两分钟隐藏、取消撤销、删除成功/失败、重开及切页明文清理正常。
7. 请求/异常独立分页，搜索只作用于本页；详情请求不受异常分页限制，快速切换/关闭后不出现另一条请求的延迟数据；搜索和列表刷新不抢输入焦点。
8. 运行中、无首个输出、完整成功、HTTP 200 后失败/断流、取消、恢复中断各检查时间线、错误和复制文本，保留毫秒、未知与零值语义。复制顺序与展示一致，无请求正文、工具参数或凭据。
9. 模型搜索、刷新、复制准确 ID、用于接入和已有测试记录保留；文本测试消耗额度，仅在另行授权真实调用后实测。
10. 设置中原有在线更新、安装确认、主题保存、托盘/退出入口保留。只检查界面不会自行安装更新、重放请求或修改防火墙。
