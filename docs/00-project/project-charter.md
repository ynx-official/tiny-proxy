## 目标

提供一个用户自己运行的原生桌面应用：打开应用、在官方浏览器页面登录、选择可用模型、启动监听，即可在自己的其他设备或 Agent 中配置 Base URL、网关密钥和模型 ID。

主要价值是把账号连接、流式协议适配和网络服务管理集中到一个桌面工具中。不需要用户安装 Codex、手动提取 Token、维护数据库服务或运行命令行后台。

## 已确认

- 使用者仅本人，可有多个客户端与设备。
- 技术栈为 GPUI、GPUI Kit、Tokio、Axum、SQLite。
- 纯桌面；局域网及个人 VPN 访问。
- 从零登录、流式转换、标准模型 API 为核心。
- 参考 cursor-byok-main；不做 Cursor 接管、证书安装、Agent 循环。
- 本轮只写方案和计划。

## 成功标准

在没有 Codex 的目标 Windows 环境中，安装应用并完成登录；本机及第二台设备能通过网关完成文本流和客户端工具调用往返；关闭窗口仍能按设置在托盘运行；撤销密钥、退出账号和停止服务具有可验证行为。

上述是交付目标，目前均未实测。详细指标与边界由 [验收场景](../01-requirements/acceptance/mvp.md)定义。

## 交付物

桌面安装包、模型 API 兼容说明、连接引导、最小诊断能力、测试证据和用户文档。首次发布只承诺经过验证的平台、客户端版本及模型能力。

不以包含网页管理端、支持所有 OpenAI 功能、达到某个未经测量的性能数字作为首版完成标准。
