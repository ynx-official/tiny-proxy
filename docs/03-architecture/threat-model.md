# 权限矩阵与威胁模型

状态：Review  
最后更新：2026-10-13  
关联文档：[数据模型](data-model.md)、[API](api-contracts.md)、[决策表](../01-requirements/assumptions.md)

## 信任边界

用户桌面操作 → 本机应用服务 → 凭据存储；其他设备 → Axum API → 上游 HTTPS。当前 Codex 设备码授权通过固定上游轮询完成，没有本地浏览器回调监听；旧 SIWC 回调模块不在应用运行路径。

本方案仅面向本人设备的局域网/个人 VPN。互联网公开监听、多用户授权和公网 TLS 终止不在首版范围内。

## 权限矩阵

| 能力 | 本机桌面所有者 | 持有效网关密钥的客户端 | 无密钥客户端 |
|---|---|---|---|
| 登录/退出/切换上游连接 | 是 | 否 | 否 |
| 创建/撤销网关密钥 | 是 | 否 | 否 |
| 修改监听与运行设置 | 是 | 否 | 否 |
| 模型列表与推理 | 是（内置测试） | 是（受模型和并发规则限制） | 否 |
| 读取上游凭据 | 不提供显示/导出 UI；仅 AuthService 使用 | 否 | 否 |
| 请求记录与诊断导出 | 是（脱敏） | 仅本次响应及请求 ID | 否 |
| 执行本机命令/文件工具 | 应用不提供此能力 | 否 | 否 |

客户端密钥首版仅隔离标识、撤销和并发，不做复杂角色权限或计费额度。持钥客户端能消耗当前活动连接的模型额度；用户需主动选择哪些设备持钥。

## 威胁与控制

| 威胁 | 设计控制 | 验证 |
|---|---|---|
| 局域网未授权调用 | 所有模型 API 鉴权，默认 loopback，指定网卡绑定 | 缺失/错误/撤销密钥，无上游请求 |
| 明文 LAN 被监听 | 首选加密个人 VPN；普通 LAN HTTP 明确显示明文属性 | 网络配置文案与 VPN 实测 |
| 网关 Token 泄漏 | 随机高熵、默认遮盖、摘要鉴权 + DPAPI 密文恢复、可逐 key 撤销、日志脱敏 | 数据库/日志/诊断包检索 |
| 上游凭据泄漏 | 用户级操作系统保护、限制文件 ACL、只在 AuthService 解密 | 加密存储/失败不降级测试 |
| 设备码泄漏/会话混用 | 固定 HTTPS 端点、短期尝试、取消与过期、代码不写日志；新旧认证凭据隔离 | 拒绝/超时/取消、身份变更刷新拒绝、隔离迁移测试 |
| 两个进程同时刷新 | 单实例锁 + 单注册刷新锁 + generation | 并发刷新与重复启动测试 |
| 客户端请求任意内网地址 | 上游地址固定；图片仅接受 Base64 data URL，不抓取图片 URL，不接受回调或任意代理地址 | 图片 HTTP(S)/file URL 拒绝且无上游调用；URL/头注入测试 |
| 图片正文泄漏或资源耗尽 | 图片复用鉴权与 2 MiB 总请求限制；校验编码但不解码像素；不记录图片正文 | 畸形图片错误无正文、无钥 401、超限 413、拒绝请求不上游 |
| 慢连接或超大请求 | 请求体、并发、头读取/请求读取、事件和总时限约束 | 大体积/slowloris/慢下游测试 |
| 流中断被当成成功 | 严格终态状态机 | 各事件位置截断 |
| 客户端工具在本机执行 | 没有执行器，工具调用仅协议数据 | 用看似危险的工具名验证只转发 |
| 日志泄露提示词/工具参数 | 只保存结构化元数据；错误消息白名单/截断/脱敏 | 合成敏感值注入后的全输出扫描 |
| 恶意网页调用 localhost | 不开 CORS、无 Cookie、Bearer 必填、无远程管理路由 | 跨源/预检/无钥调用失败 |
| 不受信任重定向泄露凭据 | 上游请求不自动向非允许目标跟随重定向 | 跨域 30x 不携带认证 |
| VPN/网卡变化扩大暴露 | 明确地址列表，失去地址停止，不降级 0.0.0.0 | 网卡移除及恢复 |
| 撤销与在途请求竞争 | 密钥记录删除提交后鉴权失效，并取消关联任务；提交失败保留记录并显示错误 | 撤销前后竞态、失败保留与其他密钥隔离测试 |

不自动开放系统防火墙、不安装 CA、不修改系统代理、不映射路由器端口。远程使用优先个人 VPN；在不可信 LAN 上需要保密时应使用 VPN，不能把 API Key 当作传输加密。

## 隐私和删除

默认不记录提示词、回答、工具参数或完整授权地址。不发送遥测。诊断导出由用户主动操作，只含版本、状态、脱敏元数据和错误码。

保留时间与清理规则按业务规则待确认。删除 Token 后不再使用，但数据库历史页或备份的物理擦除不在默认保证内。远端会话撤销与本地删除结果分开展示。

## 剩余风险

同一 Windows 用户下的恶意程序、管理员或进程内存转储不在 DPAPI 的完全保护范围。持有效网关密钥的本人设备也可能发送高消耗请求，服务用并发和时限限制损失，但不承诺精确上游花费控制。

上述是具体设计边界，不据此扩大为企业安全平台。发布前验证当前边界即可。
