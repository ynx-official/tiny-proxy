# 本地账号状态与额度查询

状态：Approved（范围由用户于 2026-10-13 明确提出）  
最后更新：2026-10-13  
关联文档：[数据模型](../data-model.md)、[认证](../authentication.md)、[验证记录](../../06-delivery/implementation-status.md)

用户要求密钥可再次查看/复制，账号逐条保存，模型目录、测试结果及时间、额度查询结果均持久化，并每小时或手动查询额度。本决定替代“密钥只展示一次、单个账号、目录和测试仅在内存”的当前实现规则。

- SQLite 保存多账号，凭据继续使用用户级 DPAPI；账号身份以 subject + ChatGPT account ID 绑定，同一身份重复授权更新原记录。原单账号会话在应用服务首次访问时迁移，保留原密文依据，不要求重登。
- 网关仍只有一个手动选择的活动账号，不自动轮换；运行网关时必须先停止才能切换或新增授权。刷新与查询绑定具体账号，不能因活动指针改变而写错账号。
- 新客户端密钥保存摘要用于鉴权，另存 DPAPI 密文用于本人查看/复制；旧摘要不能还原，不伪造密钥、不自动撤销。界面默认遮盖，按需显示。
- 目录快照和每次显式文本测试按账号保存；测试包含开始/结束时间、状态、结果或安全错误、使用量。中断测试启动时标记为中断。普通 Agent 请求正文不因此落库。
- 查询参考 wham/usage 和只读 rate-limit-reset-credits；不调用 consume。保留最近成功快照、最后尝试时间及失败说明，失败不把已有余额改成零。未知值为 NULL。
- 每个账号按最后尝试时间间隔一小时查询；应用打开后补查到期账号，关闭期间不运行后台服务。自动与手动请求合并，避免同账号重复查询。手动刷新重新计算下一次自动查询时间。
- 额度显示上游窗口名称/时长、剩余百分比、重置时间、可用重置次数；不推算上游未提供的资格或次数。重置时刻是上游额度窗口时间，自动查询时刻另列。

验收：升级后原账号可用；多账号不互相覆盖；重启恢复密钥/目录/测试/额度；密钥明文不进入 SQLite；失败/取消/过期可辨别；手动与小时任务去重；外部 API 无账号管理或密钥读取入口。
