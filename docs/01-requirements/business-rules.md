# 业务规则

状态：Review  
最后更新：2026-10-14  
关联文档：[API](../03-architecture/api-contracts.md)、[认证](../03-architecture/authentication.md)、[验收](acceptance/mvp.md)

| ID | 规则 |
|---|---|
| B01 | 仅本人使用；外部 Agent 持网关密钥，不持上游 OAuth Token。 |
| B02 | 不以安装或读取 Codex 缓存作为首次登录条件；不自动导入其他应用登录态。 |
| B03 | 身份登录成功与获得模型调用权限是两种状态；必须分别判断。 |
| B04 | 同时只有一个活动上游连接；新请求使用其快照，执行中不切换连接或模型。 |
| B05 | 不自动轮换账号、切换费用来源或退回另一认证路线。 |
| B06 | 每个 API 请求只发起一轮模型推理；工具调用由外部 Agent 执行并发起后续请求。 |
| B07 | 所有 /v1 端点均验证网关密钥，包括模型列表；没有免鉴权的本机旁路。 |
| B08 | 上游请求结束必须有可信终态；连接关闭、HTTP 200、某个 item.done 均不代表生成成功。 |
| B09 | 2026-10-14 用户明确要求默认信任下游字段，替代此前严格拒绝及禁止跳过扩展参数的规则。未知/用不到的字段接收后跳过；可映射的原生值交给上游判断，不检查可选字段类型、枚举、名称范围或工具历史配对。只保留协议转换所需结构，已知跳过参数用固定响应头提示；语义与历史快照见 [API 契约](../03-architecture/api-contracts.md#默认信任下游字段2026-10-14)。 |
| B10 | 流式请求在任何输出发出后不自动重放；不因网络超时重新生成整段答案。 |
| B11 | 原生 Responses 保留事件及回放数据，客户端原生值默认信任；Chat 不承诺隐藏推理回放。2026-10-14 替代此前 reasoning_content 字符串/null 与角色限制：任意值作为扩展元数据接收后跳过，不拼入正文；assistant 非空值固定提示一次，见 [API 契约](../03-architecture/api-contracts.md#chat-推理历史兼容规则)。 |
| B12 | 客户端断开、密钥撤销、账号退出、立即停止均取消受影响请求；切换账号不取消原账号在途请求。 |
| B13 | 2026-10-14 用户确认 Windows 主窗口关闭默认收起到托盘，后台网关和任务继续运行；点击托盘或重复打开同一数据目录的应用恢复窗口。托盘不可用保持窗口可操作并提示，通过托盘或设置主动退出必须结束监听与后台任务。Windows EXE 启动不附带控制台窗口。本次不新增关闭行为开关；macOS 托盘仍待实施。 |
| B14 | 本地日志仅记录元数据，不记录请求/响应正文、工具参数、授权 URL 或凭据。2026-10-13 用户再次选择“只保存元数据”：持久化起止时间、阶段和结构/使用量信息，失败异常独立保存并关联请求 ID，规则以 [请求诊断](../05-operations/request-diagnostics.md) 为准。 |
| B15 | 应用启动完成本地恢复后默认启动代理；需有已登录账号和未撤销的客户端密钥。沿用上次成功监听地址，未配置时为 127.0.0.1:8787；缺少前提时提示配置，监听失败保留应用和手动重试入口。手动停止只影响本次运行，开机自启仍不默认开启。 |
| B16 | 监听地址按网卡明确选择；不默认绑定所有网卡，不自动改防火墙、路由器或 VPN。 |
| B17 | 额度不足与授权失效分开显示；未知额度不显示为 0，不承诺推断重置时间。 |
| B18 | 本机逻辑删除与远端撤销是不同结果；退出时分别报告，不声称清理本地就撤销了远端会话。 |
| B19 | 2026-10-13 用户批准 Base64 图片输入；仅转发用户消息的受支持图片，不抓取地址、不读取本地路径、不持久化图片正文。格式与请求体规则以 [图片输入契约](../03-architecture/api-contracts.md#图片输入兼容规则) 为准。 |
| B20 | 2026-10-13 用户要求“撤销了的 key 就彻底删除不展示”：撤销成功删除整条客户端密钥记录（含摘要与 DPAPI 密文），从列表和当前明文预览移除，重启后不再出现；升级删除历史已撤销记录。删除失败保留记录并提示错误，不影响其他有效密钥。旧值按无效密钥拒绝，关联在途请求取消。 |
| B21 | 2026-10-13 用户在确认请求体 413 后要求“代码里面改为不限制”：取消 Chat/Responses 请求体大小上限，替代此前 2 MiB 限制；大文本、工具历史及 Base64 图片遵循同一规则。鉴权、JSON 和转换所需结构仍检查；2026-10-14 取消字段白名单及可选语义严格校验；资源边界见 [API 契约](../03-architecture/api-contracts.md#图片输入兼容规则) 及 [威胁模型](../03-architecture/threat-model.md#剩余风险)。 |

## 推荐运行默认值

2026-10-13 根据 index 报错及用户指定 codex-proxy-dev 参考，B09/B11 追加已知客户端元数据与 null 占位的规范化规则。该历史规则已由 2026-10-14 的默认信任方案替代；实际历史仍保留，但未知字段跳过且工具配对由上游判断；权威范围见 [客户端历史与空值契约](../03-architecture/api-contracts.md#客户端历史与空值兼容规则)，验收 A17g/A17h。

2026-10-13 用户明确要求“项目启动的时候 默认同时启动代理”，据此更新 B15，替代原“默认不自动监听”。地址持久化及错误处理见 [启动规则](../05-operations/desktop-operations.md#代理自动启动)，验收为 A42—A44。

以下均为待评审配置，最终以实测调整结果为准：

| 配置 | 初始值 |
|---|---|
| 默认监听 | 127.0.0.1:8787；冲突时停在错误状态，不静默换端口 |
| 网络开放 | 手动选择局域网/VPN 的具体 IPv4；IPv6 首版不启用 |
| 并发 | 全局 4、每密钥 2；无排队，超限直接 429 |
| 请求体 / 单 SSE 事件 | 2026-10-13 用户明确要求取消请求体大小限制，替代此前的 2 MiB；单 SSE 事件仍为 1 MiB |
| 非流式聚合 / 每请求缓冲预算 | 各 16 MiB；工具参数和增量队列计入预算 |
| 建连 / 响应头等待 | 15 秒 / 60 秒 |
| 上游静默 / 总时限 | 180 秒 / 15 分钟；长推理模型在实测后可调整 |
| 下游写阻塞 | 30 秒；超限取消上游 |
| 停止服务 | 先拒绝新请求、等待最多 10 秒，然后取消；提供立即停止 |
| 请求记录保留 | 最多 7 天或 10,000 条，先达到者触发清理 |
| 指标通知 UI | 合并更新，最高每秒 10 次；不逐 token 重绘 |
| 网关密钥 | CSPRNG 生成至少 256 bit 随机秘密；数据库保存鉴权摘要及用户级 DPAPI 密文，用于本人查看/复制 |

日志保留和删除为隐私决策，批准前不能将这些推荐值当作已确认规则。



2026-10-13 用户追加本地持久化与多账号额度查询范围，适用规则及验收以 [ADR 0004](../03-architecture/adr/0004-local-account-state.md) 为准。

## 在线更新规则（2026-10-13 追加）

- U01：仅 Windows x64/macOS arm64，共四个应用产物；版本唯一来源、发版资料一致性与标签规则见 [发版流程](../06-delivery/release-process.md)。
- U02：检查最新正式版，只读；默认启动检查，支持定时/关闭与提醒偏好持久化；下载和安装均需用户点击，安装前再次确认停止网关及在途请求。
- U03：匹配安装方式、验证大小与 SHA-256；错误内容不能绕过校验，失败不静默替换；来源降级边界见 [ADR 0005](../03-architecture/adr/0005-online-update-release.md)。
- U04：macOS 钥匙串保存随机加密密钥，SQLite 存 AES-256-GCM 密文；缺失/拒绝/损坏时失败，不降级明文、不覆盖旧加密密钥。
- U05：手动工作流只上传 artifacts，正式标签要求 Approved 和发布日期；正式发布与 Git 操作仍需单独授权。
