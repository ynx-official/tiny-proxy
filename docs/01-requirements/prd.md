## 产品定义

Tiny Proxy（工作名）是个人桌面模型网关。外部 Agent 连接应用提供的 HTTP API，应用使用自己管理的上游登录凭据进行推理。

标准兼容指 [API 契约](../03-architecture/api-contracts.md)明确列出的子集，不意味着完整复制 OpenAI 平台或把订阅访问权限转换为任意 API 权限。

## 首版能力

| ID | 能力 | 可观察结果 |
|---|---|---|
| R01 | 从零登录 | 无 Codex 安装或缓存仍能发起浏览器登录；显示取消、超时、权限不足与成功状态 |
| R02 | 连接管理 | 可保存本人多个账号/工作区注册，手动选择一个活动连接；支持重新登录和退出 |
| R03 | 凭据续期 | 并发请求只触发一次同会话刷新；失效时停止推理并引导重新登录 |
| R04 | 模型发现 | 展示当前连接可见模型，复制真实模型 ID；不伪造套餐额度与模型权限 |
| R05 | 监听管理 | 启停服务、选择本机/局域网/VPN 地址、设置端口、报告冲突 |
| R06 | 客户端密钥 | 为设备或 Agent 建立命名密钥；DPAPI 加密保存，可随时查看/复制；旧摘要密钥不能还原；撤销后删除且不再展示，历史已撤销记录升级时清理，依据 [B20](business-rules.md) |
| R07 | 标准 API | GET /v1/models；POST /v1/chat/completions 和 /v1/responses；流式及非流式 |
| R08 | 文本与工具 | 多轮文本、函数工具增量、多个交错工具调用、工具结果回传 |
| R09 | 可靠流处理 | 断流不伪报成功；下游断开取消上游；错误与使用量具有明确语义 |
| R10 | 桌面体验 | 连接向导、概览、模型、接入、请求记录、设置、托盘 |
| R11 | 诊断与恢复 | 显示脱敏错误和请求 ID；重启恢复配置；不保存提示词或模型正文 |
| R12 | 安装使用 | 在无 Rust、Node、Java、Codex 的干净目标机器上运行 |

R02 的多连接是保存和手动选择，不是账号池。一个请求在入口确定连接与配置快照，执行中不切换账号。

## 核心使用流程

首次启动 → 官方浏览器授权 → 确认模型调用权限 → 同步模型 → 用户点击连接测试 → 创建网关密钥 → 选择访问地址 → 启动服务 → 在 Trae 填写三项连接信息 → 发起文本和工具调用测试。

日常启动 → 恢复上次配置与连接状态 → 账号和客户端密钥齐备时自动监听上次成功地址 → 查看状态。2026-10-13 根据用户“默认同时启动代理”的要求更新，规则见 [B15](business-rules.md)，托盘仍是后续目标。

## MVP 完成边界

先支持文本和客户端 function tools。2026-10-13 用户在 image_url 接入报错后批准“按参考项目补齐”，追加用户消息中的 Base64 图片输入，替代原来图片全部后置的范围；规则以 [API 契约](../03-architecture/api-contracts.md#图片输入兼容规则) 为准。结构化输出、音频、文件上传、嵌入、完整 Anthropic API、服务器保存会话和 WebSocket 仍不属于 MVP；不支持的输入返回具体错误，不静默丢失。

不提供 Web 管理端、服务器独立部署、Windows 服务、系统级守护进程、多租户、计费、账号自动轮换、插件平台、自动更新系统或 Cursor 中间人代理。是否扩展在后续版本另行决策。

## 非功能目标

- UI 线程不执行阻塞网络和数据库任务。
- 凭据不进入普通日志、诊断包或客户端响应。
- 请求有明确的大小、并发、超时和内存边界。
- 接入 API 不具备本机管理权限。
- 生命周期和协议终态可测试；性能预算与测试方法见 [质量计划](../04-quality/verification-plan.md)。
