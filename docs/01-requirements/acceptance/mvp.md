## 登录与存储

| ID | Given / When | Then |
|---|---|---|
| A01 | 干净应用目录且机器无 Codex；用户从桌面完成官方登录 | 身份校验成功、显示权限、保存受保护凭据；能列出当前模型并完成一次真实推理 |
| A02 | 设备轮询收到拒绝、过期、无效 Token；或刷新返回不同账号 | 明确失败，不覆盖原有效连接；仅使用当前 Codex 会话的凭据 |
| A03 | 用户拒绝授权、取消或超时 | 设备轮询结束，UI 可重新获取代码；原活动连接保持 |
| A03a | 设备轮询返回 403/deviceauth_authorization_pending、404 空响应或其他等待格式 | 保持等待，收到有效授权结果后完成交换；取消/到期仍能结束 |
| A03b | 申请设备码或交换 Token 返回 403；轮询返回 5xx | 明确失败并标出阶段，不误当作等待，不显示上游响应体 |
| A04 | 已登录但缺模型调用权限 | 不向模型端点发送请求；UI 提供明确恢复动作 |
| A05 | 同注册 Token 即将过期，16 个调用方同时需要凭据 | fake 上游只收到一次刷新；所有有效请求使用同一新 generation |
| A06 | 刷新超时/5xx 与终态 invalid_grant 分别发生 | 前者保留凭据并提示暂不可用；后者停止使用失效凭据并要求重登 |
| A07 | Token 保护或 SQLite 提交失败 | 不明文保存、不发布未提交新 Token；恢复结果明确 |
| A08 | 退出账号时远端撤销失败 | 本地停止请求并删除可用 Token，明确显示远端撤销未确认 |

## 标准 API 与流

2026-10-13 根据真实文本探测补充兼容验收：缺少 Content-Type 的合法 SSE 仍须通过完整事件和终态校验；JSON/HTML/空流不得视为成功。completed.output 为空时，仅允许从同一响应完整且一致的 output_item.done 重建；缺少完成事件、未完成条目或冲突必须失败。依据及实测边界见 [开发验证记录](../../06-delivery/implementation-status.md)。

| ID | Given / When | Then |
|---|---|---|
| A09 | 无密钥、错误密钥或已撤销并删除密钥请求任意 /v1 路由 | 401 invalid_gateway_key，且 fake 上游请求数为 0；撤销与已通过鉴权请求发生竞态时按取消规则终止 |
| A10 | 列模型后切换本人账号 | 列表只属于当前账号；模型 ID 与实际推理一致，旧权限不沿用 |

| A13 | Trae 接收工具调用、在客户端执行、再发送工具结果 | 网关正确关联 call_id，模型完成下一轮；网关自身无工具执行 |
| A14 | 文本 item.done 之后、response.completed 之前断流 | 标记中断；不发 stop/tool_calls 成功终止或 [DONE] |

| A16 | incomplete 分别携带长度、过滤和未知原因 | 按契约区分；不统一写 length 或 completed |
| A17 | 请求不支持字段、未知模型、n>1 或不完整工具历史 | 400/404 且指明字段/原因；未发上游请求 |
| A17a | Chat 带 max_tokens/max_completion_tokens，或 Responses 带 max_output_tokens，分别请求 JSON/SSE | 正整数兼容接收、上游不含长度限制，响应头列出未生效字段并提示，正文与终态保持完整；null 等同未设置且不加提示 |
| A17b | 上述长度字段为零、负数、小数或错误类型；或与其他不支持字段一起发送 | 400 并指明字段，不调用生成上游；两个 Chat 长度字段同时存在时各自校验 |
| A17c | Chat user 携带 Base64 image_url 或 Responses user 携带 input_image，单图、多图、纯图片及图文混合，分别 JSON/SSE | 图片按 input_image 发往上游，图文顺序/字节/detail 保留；省略 detail 补 auto，终态完整 |
| A17d | 图片编码/MIME/detail 错误、远程或本地文件 URL、未知字段、非 user 图片、无密钥或请求超过 2 MiB | 分别 400/401/413；生成上游计数不增加，错误不包含图片数据；原工具历史校验保持 |
| A17e | Chat assistant 文本/工具历史携带字符串或 null reasoning_content，分别 JSON/SSE，可同时有长度参数 | 请求正常转换，正文及工具链原样保留；推理文本不进入上游正文/指令/回放项；非空值仅提示一次且警告准确，空值不产生推理提示；后续模型错误保留状态与提示 |
| A17f | reasoning_content 类型错误、出现在非 assistant/顶层/Responses 消息，或同时携带未知字段、无效工具历史 | 400 且不调用生成上游，不回显推理内容；Responses 原生 reasoning/encrypted_content 回放保持 |
| A17g | 客户端合并 Chat 流式工具增量保留 index，带结果 name/空可选字段后再次请求，首轮和后续分别使用 JSON/SSE | 按 call_id 配对并保留顺序、参数原文和结果；index 不转发、不排序；拒绝文本保留，长度/推理提示准确；函数工具缺省 schema、可选空值和原生推理状态按契约转换 |
| A17h | index 类型或位置错误、工具结果 name 不匹配、未知字段即使 null、非空未支持参数、工具链损坏或无效推理状态 | 400；HTTP 无新增生成上游调用；工具参数/schema 内的 index/status/null 不被递归清洗 |
| A18 | stream=false，分别上游成功、失败、超聚合预算 | 成功 JSON；失败非 2xx；超限取消上游，不返回半个成功对象 |
| A19 | 请求 include_usage=true/false，上游有/无统计 | usage 发送符合请求；未知不伪造；缓存/推理子项不重复加总 |
| A20 | Responses 客户端回传可用 reasoning item 与工具结果 | 支持字段、ID 和顺序保留；终态真实；不经过有损 Chat 重建 |
| A21 | Chat 历史不带加密推理项进行多轮工具调用 | 目标模型真实通过才列为 Chat 工具兼容；不通过则明确限制 |

A17a/A17b 于 2026-10-13 根据第三方 Agent 接入报错及用户明确批准的兼容取舍新增，替代 A17 对合法长度参数的拒绝要求。实际自动验证证据与真实客户端边界见 [开发验证记录](../../06-delivery/implementation-status.md)。

A17c/A17d 于 2026-10-13 根据用户“按参考项目补齐”的批准新增，替代原图片全部拒绝规则。自动验证和真实 Codex/客户端图片验证分别记录，不能互相替代。

A17e/A17f 于 2026-10-13 根据 reasoning_content 报错追加，限定为 [Chat 推理历史兼容](../../03-architecture/api-contracts.md#chat-推理历史兼容规则)，不代表已验证真实客户端或上游推理连续性。

A17g/A17h 于 2026-10-13 根据 index 报错及用户要求参考 codex-proxy-dev 成组处理追加，范围见 [客户端历史与空值契约](../../03-architecture/api-contracts.md#客户端历史与空值兼容规则)。仍需真实 Agent 重试，模拟工具执行不等于真实 Codex 工具验收。
